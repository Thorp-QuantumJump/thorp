# 홈 지표 카드 기간 전환

- 대상: 홈의 주식시장 핵심 지표 5개, 경기·물가·심리 핵심 지표 6개.
- 기본 카드는 각 지표의 관측 기준월을 포함한 최근 3개월을 표시한다.
- 마우스를 올리거나 `5년 보기` 버튼을 누르면 해당 카드만 확대된다. 연도·값 눈금이 있는 최근 60개월 차트를 그리며 다른 카드의 위치는 유지한다.
- 작은 카드와 확대 패널을 Motion의 동일한 `layoutId`로 연결한다. 약 0.48초 동안 크기·위치가 이어지고, 내용과 차트 선이 순서대로 나타난다. 닫을 때도 원래 카드로 복귀하며 퇴장 중 패널은 입력·초점을 받지 않는다.
- 커서 이탈, 닫기 버튼, Escape, 카드 밖으로 키보드 초점 이동 시 닫힌다. 모바일은 버튼으로 열고 닫는다. 동시에 열리는 카드는 하나다.
- 마우스로만 열어 초점이 카드 밖에 있어도 Escape로 닫고 원래 카드 버튼으로 초점을 돌린다. 전역 키 이벤트는 열린 동안에만 등록하고 닫힘·페이지 이탈 시 해제한다.
- 사용자의 모션 감소 설정에서는 확대·선 그리기 애니메이션을 생략한다.

## 데이터 연결

현재 장기 이력은 `indicatorHistoryMock.ts`에서 생성하는 고정 모의 데이터다. 실제 과거 통계로 사용하면 안 된다. 기존 최근 6개월 값과 최종 값은 유지하며, 원본 `marketMock.ts`와 분리한다.

추후 API 연결 시 `Indicator.series`에 날짜순 `{ date, value }` 목록을 공급한다. 월간은 `YYYY-MM`, 일간은 `YYYY-MM-DD`를 사용하며 프런트엔드에서 실제 데이터의 빈 날짜를 임의로 보간하지 않는다. 3개월/60개월은 데이터 개수가 아닌 관측 기준월로 자른다. 표시 범위는 차트의 실제 시작·종료 날짜를 따른다.

현재 화면의 5년 표시는 60개월 mock을 전제로 한다. 실제 API 이력이 짧거나 부족하면 기간 안내 및 로딩·실패 처리는 API 연동 작업에서 실제 제공 범위에 맞게 연결한다.

날짜는 형식뿐 아니라 월별 일수·윤년도 검사한다. 잘못된 기준일은 빈 배열을 반환하고, 잘못된 개별 관측일·유한하지 않은 값은 제외한다. 월 단위 기준일은 해당 월말까지, 일 단위 기준일은 그 날짜까지만 포함한다.

날짜 회귀 테스트: `frontend`에서 Node.js 24 기준 `node --test src/utils/indicatorHistory.test.ts` 실행. 별도 테스트 패키지는 추가하지 않는다.
