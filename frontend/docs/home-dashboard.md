# 홈과 대시보드 화면 분리

## 화면과 경로
- `/` → `LandingPage`: 기존 서비스 소개. 시작하기는 `/home`으로 이동한다.
- `/home` → `HomePage`: 기존 대시보드 전체. 장기 차트 캐러셀, 시장·거시지표, 유사 시장 비교, 추천 전략, 데이터 출처를 유지한다.
- `/dashboard` → `DashboardPage`: 한 화면에서 시장 상황 → 가로 지표 요약 → 추천 전략을 확인하는 요약 화면.
- `/backtest` → 기존 백테스트 화면.
- 공통 헤더와 서랍 메뉴에서 홈·대시보드·백테스트로 이동한다. 로고는 홈, 처음으로는 랜딩으로 이동한다.

## 구성과 재사용
- `components/home/`: 홈 전용 히어로·캐러셀·장기 차트·유사 시장·출처.
- `components/market/`: 두 화면이 공유하는 지표 카드·확대 차트·스파크라인·추천 전략.
- `components/dashboard/`: 간결한 시장 상황 요약.
- `styles/MarketLayout.module.css`: 공통 시장 테마·푸터·간결한 섹션 간격. 기존 CSS Module과 차트 애니메이션을 재사용한다.
- 대시보드는 별도의 가로 지표 스트립을 사용하고 시장/거시 토글만 제공한다. 상세 해석과 5년 확대는 홈에 유지한다.
- 추천 전략은 기존 컴포넌트의 `compact` 옵션으로 근거와 실행 동선만 남긴다. 홈의 상세 카드와 간격은 유지한다.
- 화면 이름에 종속되었던 데이터·타입·포맷 파일을 `marketMock.ts`, `market.ts`, `marketFormat.ts`로 변경한다.

## 데이터와 상호작용
- 두 화면은 동일한 `marketMock`을 사용한다. 날짜·수치·추천 근거를 화면 안에 복제하지 않는다.
- 상단은 경기·물가·시장 위험 상태와 짧은 설명만 표시한다.
- 지표 요약은 작은 시장/거시 버튼으로 전환하며 값·변화량·최근 3개월 추세만 표시한다.
- 기존 최근 3개월 미리보기·5년 확대·Escape 닫기·모션 감소 설정을 유지한다.
- 추천 전략은 기존 백테스트 진입 동선을 사용한다. 특정 전략 자동 선택은 현재 지원하지 않는다.
- 데이터는 실제 현재 시장이 아닌 UI 예시다. 분석 기준일·예시 표시를 유지한다.
- `MarketData`는 화면 모델이며 확정된 API 계약이 아니다. 실제 연동 시 `api/`에서 DTO를 받고 화면 모델로 변환하며 로딩·빈 결과·오류 상태를 연결한다.

## 검증
- lint, build, 날짜 유틸리티 회귀 테스트, diff 공백 검사.
- 랜딩 → 홈 → 대시보드 → 백테스트와 URL 직접 접근.
- 데스크톱·모바일 배치, 지표 분류 전환, 확대 패널과 키보드 닫기, 메뉴 이동.
