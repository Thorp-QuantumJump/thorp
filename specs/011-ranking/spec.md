# Feature Specification: 랭킹

**Feature Branch**: `011-ranking`

**Created**: 2026-09-03

**Status**: Draft

**Input**: User description: "F11. 랭킹 — Thorp에서 동일한 비교 기준을 만족하는 전략 또는 가상투자 성과를 순위 형태로 탐색한다. 사용자는 순위의 지표·기간·산정 기준, 각 항목의 성과·위험 및 상세 근거를 확인할 수 있어야 한다. 비교 불가능한 결과를 섞거나 비공개 결과를 동의 없이 포함하지 않고, 과거 순위를 미래 수익으로 표현하지 않는다. 저장·공유, 추천, 실제 투자, 구체적인 랭킹 알고리즘과 시각 디자인은 제외한다."

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 비교 가능한 랭킹 탐색 (Priority: P1)

사용자는 백테스트 전략 또는 가상투자 중 한 종류를 선택하고, 지원되는 평가 기간과 순위 지표를 기준으로
랭킹을 확인한다. 하나의 랭킹에는 시장·대상 범위, 평가 기간, 초기 조건, 데이터 기준과 지표 정의가 같은
결과만 포함되며, 사용자는 순위와 함께 기준값과 마지막 산정 시점을 확인한다.

**Why this priority**: 비교 가능한 결과를 같은 기준으로 정렬해 무엇을 먼저 살펴볼지 결정하는 것이 랭킹의
핵심 사용자 가치다. 이 경계가 불명확하면 순위 자체가 오해를 만든다.

**Independent Test**: 비교 조건이 같은 결과와 기간·데이터·초기 조건 또는 결과 종류가 다른 결과를 함께
준비한다. 특정 기간과 지표의 랭킹을 열었을 때 적격 결과만 순위에 포함되고, 백테스트와 가상투자가 별도
랭킹으로 제공되며, 지표 이름·우수 방향·평가 기간·산정 시점이 표시되는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 동일한 비교 조건을 충족하는 공개 백테스트 결과들, **When** 사용자가 기간과 순위 지표를 선택하면,
   **Then** 해당 조건의 전략 랭킹이 지표의 우수 방향에 따라 순서와 기준값을 제공한다.
2. **Given** 동일한 공통 기간을 완전히 포함하는 공개 가상투자 결과들, **When** 사용자가 가상투자 랭킹을
   선택하면, **Then** 그 기간까지 확정된 가상 성과만 별도 순위로 제공된다.
3. **Given** 서로 다른 결과 종류, 평가 기간, 대상 범위, 데이터 기준 또는 지표 정의 버전의 결과, **When**
   랭킹 적격성을 판단하면, **Then** 하나의 랭킹에 섞이지 않고 해당 결과의 제외 또는 별도 집단 사유를
   확인할 수 있다.
4. **Given** 적격 결과가 없는 기준 조합, **When** 사용자가 랭킹을 열면, **Then** 빈 순위를 임의 항목으로
   채우지 않고 현재 기준과 결과가 없는 이유를 표시한다.
5. **Given** 같은 랭킹을 다시 조회한 경우, **When** 산정 시점이 바뀌지 않았다면, **Then** 동일한 순위,
   기준값과 포함 항목을 제공한다.

---

### User Story 2 - 산정 기준과 성과·위험 확인 (Priority: P2)

사용자는 랭킹이 어떤 결과를 포함하고 어떤 지표를 어느 방향으로 정렬했는지 확인한다. 각 항목에서 순위
기준값뿐 아니라 공통 수익·위험 정보, 전략 식별 정보, 평가 기간과 결과 성격을 함께 보며 높은 순위가 큰
위험이나 짧은 관측 기간을 가릴 수 있음을 판단한다.

**Why this priority**: 순위 숫자만 제시하면 공정성을 검증할 수 없고 위험을 무시한 선택을 유도할 수 있다.
사용자가 기준과 맥락을 읽을 수 있어야 랭킹을 참고 자료로 사용할 수 있다.

**Independent Test**: 알려진 공통 지표 값을 가진 적격 결과들로 랭킹을 산정해 지표 정의·단위·우수 방향,
평가 기간, 비교 조건, 동률 처리, 적격·제외 기준을 열람할 수 있는지 확인한다. 각 행에 수익과 위험 정보가
같이 표시되고 원본 공통 지표 값과 일치하는지도 검증한다.

**Acceptance Scenarios**:

1. **Given** 산정된 랭킹, **When** 사용자가 산정 기준을 열면, **Then** 결과 종류, 시장·대상 범위, 평가
   기간, 초기 조건, 데이터 기준, 지표 정의·버전·단위·우수 방향, 적격·제외 기준과 동률 처리 규칙을 확인할
   수 있다.
2. **Given** 랭킹 항목들, **When** 사용자가 목록을 확인하면, **Then** 각 항목의 순위 기준값과 함께 지원되는
   공통 수익 및 위험 지표, 평가 기간, 결과 종류와 공개 주체 식별 정보를 확인할 수 있다.
3. **Given** 순위 지표 값이 같은 항목들, **When** 순위를 표시하면, **Then** 공개된 동률 규칙을 일관되게
   적용하며 사용자에게 보이지 않는 정밀도나 임의 기준으로 우열이 있는 것처럼 표현하지 않는다.
4. **Given** 우수 방향이 정의되지 않은 공통 지표, **When** 사용자가 그 지표를 선택하려 하면, **Then** 순위
   기준으로 사용할 수 없음을 알리고 보조 정보로만 제공한다.
5. **Given** 랭킹을 보는 사용자, **When** 순위 의미 안내를 확인하면, **Then** 순위는 지정한 과거 또는
   가상 관측 기간의 결과이며 미래 수익, 전략 추천 또는 투자 자문이 아니라는 사실을 알 수 있다.

### User Story 3 - 랭킹 항목의 공개 상세 확인 (Priority: P3)

사용자는 관심 있는 항목을 선택해 해당 순위를 만든 원본 결과의 공개 범위 안에서 전략 버전과 파라미터,
평가 조건, 공통 성과·위험 지표, 자산 변화와 거래 요약을 확인한다. 목록 값과 상세 값의 출처가 같고, 공개에
포함되지 않은 소유자의 다른 결과나 개인정보는 볼 수 없다.

**Why this priority**: 항목 상세는 순위의 근거를 검증하고 사례를 더 깊게 살펴보게 하지만, 비교 가능한 랭킹과
기준 공개가 먼저 제공되어야 의미가 있다.

**Independent Test**: 소유자가 공개에 동의한 결과를 랭킹에서 열어 목록의 기준값과 상세의 지표 값이
일치하는지, 전략·파라미터·평가 조건·결과 출처를 추적할 수 있는지 확인한다. 공개하지 않은 연결 결과,
개인 메모나 실제 신원 정보에 접근할 수 없는지도 검사한다.

**Acceptance Scenarios**:

1. **Given** 랭킹의 공개 항목, **When** 사용자가 상세를 열면, **Then** 공개된 전략 식별자·버전·파라미터,
   대상·평가 기간·초기 조건·데이터 기준, 공통 성과·위험 지표와 결과 출처를 확인할 수 있다.
2. **Given** 랭킹 목록과 항목 상세, **When** 같은 산정 시점의 순위 기준값을 비교하면, **Then** 값·단위·
   지표 정의 버전이 서로 일치한다.
3. **Given** 가상투자 랭킹 항목, **When** 상세를 열면, **Then** 가상 실행임과 공통 평가 기간, 마지막 포함
   데이터 시점, 가상 주문·체결 조건 및 해당 기간의 자산·거래 요약이 표시된다.
4. **Given** 공개 항목과 연결된 비공개 저장 전략·다른 결과·사용자 정보, **When** 일반 사용자가 상세를
   조회하면, **Then** 공개 동의 범위를 넘는 내용이나 비밀값은 노출되지 않는다.
5. **Given** 소유자가 공개 동의를 철회한 항목, **When** 사용자가 목록 또는 기존 상세 주소로 접근하면,
   **Then** 현재 랭킹과 공개 상세에서 제외되고 비공개 정보나 철회 전 상세를 제공하지 않는다.

---

### User Story 4 - 내 결과의 랭킹 공개 동의 관리 (Priority: P4)

결과 소유자는 랭킹 적격성을 갖춘 특정 백테스트 또는 가상투자 결과를 선택하고, 어떤 조건과 성과가 누구에게
공개되는지 미리 확인한 뒤 랭킹 참여에 명시적으로 동의한다. 소유자는 참여 상태와 적용되는 랭킹 기준을
확인하고 언제든 이후 공개를 철회할 수 있다.

**Why this priority**: 공개 결과가 충분해야 랭킹이 유용하지만, 사용자 자산의 공개는 항상 명시적 선택이어야
한다. 조회 가치보다 소유자의 통제와 비공개 기본값이 우선한다.

**Independent Test**: 기본 비공개 결과가 동의 전에는 어떤 랭킹에도 나타나지 않는지 확인한다. 소유자가
특정 결과의 공개 필드와 대상 랭킹 기준을 확인해 동의하면 적격 산정 시점부터 포함되고, 철회하면 현재 공개
목록과 상세에서 제거되는지 검증한다. 재전달된 동의가 중복 항목을 만들지 않는지도 확인한다.

**Acceptance Scenarios**:

1. **Given** 사용자가 소유한 비공개 결과, **When** 공개 동의를 하지 않으면, **Then** 적격 조건을 만족해도
   랭킹 후보·순위·상세에 포함되지 않는다.
2. **Given** 랭킹 적격 결과, **When** 소유자가 참여를 선택하면, **Then** 공개될 전략·조건·성과·위험 정보,
   공개 주체 표시, 적용 가능한 랭킹 집단과 철회 영향을 확인한 뒤에만 동의가 확정된다.
3. **Given** 확정된 공개 동의, **When** 다음 랭킹 산정 시점이 도래하면, **Then** 결과가 해당 시점에도 모든
   비교 조건을 충족할 때만 적격 항목으로 포함된다.
4. **Given** 랭킹 참여 중인 결과, **When** 소유자가 동의를 철회하면, **Then** 현재 공개 목록과 상세에서
   접근할 수 없게 되고 이후 산정에서 제외되며 철회 시점과 결과가 소유자에게 표시된다.
5. **Given** 같은 참여 또는 철회 요청이 재전달된 경우, **When** 처리하면, **Then** 중복 항목이나 충돌하는
   동의 상태를 만들지 않고 원래 처리 결과를 제공한다.

### Edge Cases

- 백테스트 결과와 가상투자 결과는 지표 이름이 같아도 데이터 생성 방식과 시간 방향이 다르므로 같은 랭킹에
  포함하지 않는다.
- 가상투자 실행의 시작 시점이 달라도 공통 평가 기간의 시작부터 종료까지 완전한 기록이 있는 경우에만 같은
  랭킹 후보가 될 수 있다. 기간 중간에 시작·종료되었거나 데이터가 누락된 실행은 그 기간 랭킹에서 제외한다.
- 실행 중인 가상투자는 랭킹 산정 시점까지 완결된 공통 평가 기간의 스냅샷만 사용할 수 있다. 아직 진행 중인
  당일 또는 불완전한 관측값을 포함하지 않는다.
- 지표 값이 계산 불가이거나 필수 위험 지표가 없으면 임의의 0이나 최하위 값으로 바꾸지 않고 해당 지표의
  랭킹에서 제외하며 사유를 표시한다.
- 지표 정의가 개정되면 서로 다른 정의 버전의 값을 같은 랭킹에 섞지 않는다. 새 정의를 적용한 별도 산정
  결과로 구분한다.
- 데이터 정정이나 결과 무효화가 발견되면 이미 공개된 산정 기록을 조용히 덮어쓰지 않는다. 새 산정 시점에
  반영하고 변경 시점과 영향을 추적할 수 있게 한다.
- 순위 기준값이 같은 항목은 공개된 동률 규칙으로 처리한다. 화면에 반올림해 같은 값으로 보이는 항목을 숨은
  소수점으로 임의 정렬하는 경우에는 비교에 사용한 실제 정밀도를 기준 설명에 공개해야 한다.
- 하나의 원본 결과를 반복 제출하거나 동의 요청을 재시도해도 랭킹에 중복 항목을 만들지 않는다.
- 같은 전략의 서로 다른 파라미터 결과가 모두 적격이면 각각 별도 항목이 될 수 있으며 전략 버전과 파라미터로
  구분한다. 이것은 특정 전략에 대한 추천으로 표현하지 않는다.
- 공개 동의 후 소유자가 저장 전략이나 설명을 변경해도 이미 동의한 불변 결과의 값과 조건을 소급 변경하지
  않는다. 다른 결과나 새 리비전은 별도 공개 동의가 필요하다.
- 공개 동의를 철회하는 순간 다른 사용자가 상세를 보고 있으면 다음 접근 확인부터 내용을 제공하지 않는다.
  비공개 감사 기록은 유지하되 공개 화면에서 이전 내용을 복구할 수 없어야 한다.
- 랭킹 항목이 하나뿐이면 1위로 표시할 수 있지만 비교 대상 수를 함께 표시해 경쟁 우위가 충분히 검증된
  것처럼 오해하지 않게 한다.
- 적격 결과 수가 매우 적거나 평가 기간이 짧으면 그대로 공개하고 표본 수와 기간 주의를 표시하며 다른
  조건의 결과로 순위를 채우지 않는다.
- 권한이 없는 사용자가 비공개 결과 식별자를 추측해 랭킹 참여·철회 또는 상세 조회를 시도하면 결과 존재
  여부, 소유자와 성과를 노출하지 않고 거부한다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 사용자는 백테스트 전략 랭킹과 가상투자 랭킹을 명확히 구분해 조회할 수 있어야 하며 두 결과
  종류를 하나의 순위에 섞어서는 안 된다.
- **FR-002**: 사용자는 제공되는 랭킹에서 결과 종류, 평가 기간과 순위 지표를 선택할 수 있어야 한다. 선택
  가능한 값은 현재 비교 가능한 적격 결과가 있는 기준 집합으로 한정해야 한다.
- **FR-003**: 하나의 랭킹은 결과 종류, 시장과 대상 범위, 평가 시작·종료 시점, 초기 자산과 실행 조건,
  데이터 기준, 지표 정의 버전 및 산정 마감 시점이 같은 결과만 포함해야 한다.
- **FR-004**: 백테스트 전략 랭킹에는 성공적으로 완료되고 전체 평가 기간·조건·사용 데이터를 추적할 수 있는
  결과만 포함해야 한다.
- **FR-005**: 가상투자 랭킹에는 공통 평가 기간 전체의 확정 기록을 가진 실행만 포함해야 한다. 실행 중인
  경우에도 산정 마감 시점 이전에 완결된 관측값만 사용하며 잠정 당일 값은 포함해서는 안 된다.
- **FR-006**: 비교 조건 중 하나라도 다르거나 필수 데이터·지표가 누락된 결과는 같은 랭킹에 포함해서는 안
  된다. 사용자는 제외 또는 별도 랭킹으로 분류된 이유를 확인할 수 있어야 한다.
- **FR-007**: 각 랭킹은 고유 식별자와 산정 시점을 가져야 하며 결과 종류, 공통 비교 조건, 포함 마감 시점,
  대상 결과 집합과 적용된 산정 기준을 추적할 수 있어야 한다.
- **FR-008**: 순위 기준은 공통 지표 정의에 우수 방향이 명시된 지표만 사용할 수 있어야 한다. 사용자에게
  지표 이름·의미·정의 버전·계산 기준·단위와 높거나 낮을수록 우수한지를 공개해야 한다.
- **FR-009**: 우수 방향이 없거나 계산 불가인 지표는 순위 기준으로 사용해서는 안 된다. 계산 불가 값을 0,
  최하위 또는 임의값으로 대체해서는 안 된다.
- **FR-010**: 랭킹은 공개된 기준 지표의 값과 우수 방향에 따라 순서를 제공해야 하며, 기준 지표 외의 비공개
  요소로 순서를 조정해서는 안 된다.
- **FR-011**: 동률 처리 규칙과 순위 번호 부여 방식을 산정 기준에 포함해야 하며 동일한 값에는 같은 규칙을
  일관되게 적용해야 한다. 정렬에 사용한 값의 정밀도도 사용자가 확인할 수 있어야 한다.
- **FR-012**: 각 랭킹은 전체 적격 항목 수, 표시 중인 항목 범위와 마지막 산정 시점을 제공해야 한다. 적격
  항목이 적거나 없는 경우에도 다른 조건의 결과를 섞지 않고 그 사실을 알려야 한다.
- **FR-013**: 각 랭킹 항목은 순위, 기준 지표 값, 전략 식별자와 버전, 공개 주체 표시, 결과 종류, 평가 기간,
  최소한 총수익률과 최대 낙폭을 포함한 공통 성과·위험 요약을 제공해야 한다.
- **FR-014**: 목록에서 제공하는 모든 지표 값은 해당 항목의 원본 결과 및 같은 산정 시점의 공개 상세 값과
  정의 버전·단위까지 일치해야 한다.
- **FR-015**: 사용자는 랭킹의 산정 기준에서 공통 비교 조건, 포함·제외 규칙, 지표 기준과 우수 방향, 동률
  처리, 산정 마감·갱신 시점 및 포함된 결과 수를 확인할 수 있어야 한다.
- **FR-016**: 사용자는 랭킹 항목을 선택해 공개에 동의된 범위의 전략 버전·파라미터, 대상, 평가 기간·초기
  조건·데이터 기준, 공통 성과·위험 지표, 자산 변화와 거래 요약을 확인할 수 있어야 한다.
- **FR-017**: 가상투자 항목 상세는 가상 실행임을 명확히 표시하고 공통 평가 기간, 마지막 포함 데이터 시점,
  가상 주문·체결 조건과 해당 기간의 성과만 제공해야 한다.
- **FR-018**: 상세는 랭킹 항목이 참조한 불변 원본 결과와 산정 시점을 식별할 수 있어야 한다. 소유자의 다른
  결과, 비공개 저장 전략, 개인 메모, 실제 신원이나 비밀값을 공개 동의 없이 노출해서는 안 된다.
- **FR-019**: 모든 백테스트와 가상투자 결과는 기본적으로 랭킹 비참여 상태여야 하며, 소유자의 명시적인
  공개 동의가 없는 결과를 후보·순위·상세 또는 적격 항목 수에 포함해서는 안 된다.
- **FR-020**: 결과 소유자만 자신의 특정 불변 결과에 대해 랭킹 참여를 동의하거나 철회할 수 있어야 한다.
  저장 전략 자체의 공유 상태나 다른 결과의 동의를 랭킹 참여 동의로 간주해서는 안 된다.
- **FR-021**: 공개 동의를 받기 전에 공개될 전략·파라미터·조건·성과·위험·공개 주체 표시, 적용 가능한 랭킹
  집단, 공개 대상과 철회 영향을 소유자에게 보여주고 명시적인 확인을 받아야 한다.
- **FR-022**: 공개 동의는 특정 결과와 공개 필드 집합을 식별해야 한다. 원본과 다른 실행, 새 결과, 변경된
  전략 리비전 또는 추가 필드에 동의를 자동 확대해서는 안 된다.
- **FR-023**: 결과가 랭킹에 참여 중이어도 각 산정 시점의 비교 조건과 데이터 완전성 검사를 다시 통과해야
  한다. 동의했다는 이유만으로 부적격 결과를 포함해서는 안 된다.
- **FR-024**: 소유자는 자신의 결과별 현재 참여·철회 상태, 동의한 공개 범위, 적용 가능한 랭킹 기준,
  동의·철회 시점과 최근 포함 여부를 확인할 수 있어야 한다.
- **FR-025**: 소유자가 공개 동의를 철회하면 현재 공개 랭킹과 상세 접근에서 해당 결과를 제거하고 이후
  산정에서 제외해야 한다. 철회 이전 정보는 공개 화면에서 다시 제공하지 않되 감사 목적의 비공개 기록은
  보존해야 한다.
- **FR-026**: 동일한 참여·철회 요청이나 동일 원본 결과의 재전달은 중복 랭킹 항목 또는 충돌하는 동의 상태를
  만들지 않아야 한다.
- **FR-027**: 각 랭킹 산정은 동일한 입력 결과 집합, 비교 조건, 지표 정의, 산정 마감 시점과 동률 규칙으로
  동일한 순위와 값을 재현할 수 있어야 한다.
- **FR-028**: 데이터 정정, 결과 무효화, 공개 철회 또는 기준 변경으로 랭킹이 달라지면 기존 산정 기록을
  조용히 덮어쓰지 않고 새 산정 시점과 변경 사유를 기록해야 한다. 공개 철회된 항목의 내용은 공개 이력에서
  가려야 한다.
- **FR-029**: 랭킹 목록과 상세에는 순위가 지정한 과거 또는 가상 관측 기간의 결과일 뿐 미래 수익, 전략
  추천, 실제 시장의 동일한 전개 또는 투자 성과를 보장하지 않으며 투자 자문이 아니라는 안내를 제공해야 한다.
- **FR-030**: 랭킹은 항목의 공개 성과와 위험을 동일한 기준으로 탐색하게 할 뿐, 사용자의 특성에 맞춘 추천,
  적합성 판단, 자동 전략 선택 또는 실제 투자 행동을 제공해서는 안 된다.
- **FR-031**: 이 기능은 비교 가능한 전략·가상투자 결과의 순위, 산정 기준·근거, 공개 상세와 결과별 참여
  동의 관리까지만 제공한다. 전략 저장·공유 자체, 추천 알고리즘, 실제 투자, 구체적인 랭킹 계산 알고리즘,
  저장·배치 기술 및 사용자 인터페이스의 애니메이션·시각 디자인은 포함하지 않는다.

### Key Entities *(include if feature involves data)*

- **랭킹 정의(Ranking Definition)**: 어떤 결과를 함께 비교할지 정한 기준. 결과 종류, 시장·대상 범위,
  평가 기간, 초기·실행 조건, 데이터 기준, 순위 지표 정의·버전·우수 방향, 적격·제외 기준과 동률 규칙을 가진다.
- **랭킹 산정(Ranking Snapshot)**: 특정 마감 시점의 불변 순위 결과. 고유 식별자, 랭킹 정의, 산정 시점,
  대상 결과 집합, 적격·제외 결과 수, 순서와 변경 사유를 가진다.
- **랭킹 항목(Ranking Entry)**: 산정에 포함된 공개 결과 하나. 순위, 원본 결과, 전략 식별자·버전·파라미터,
  공개 주체 표시, 기준 지표 값, 공통 성과·위험 요약과 상세 연결을 가진다.
- **공개 결과 스냅샷(Public Result Snapshot)**: 소유자가 공개에 동의한 특정 불변 백테스트 또는 공통 기간의
  가상투자 결과. 평가 조건, 데이터 기준, 지표 값, 자산·거래 요약과 공개 필드 집합을 가진다.
- **랭킹 참여 동의(Ranking Participation Consent)**: 소유자가 특정 결과와 필드의 공개를 명시적으로 선택한
  기록. 소유자, 대상 결과, 공개 범위, 동의·철회 시점, 현재 상태와 적용 가능한 랭킹을 가진다.
- **지표 정의(Metric Definition)**: 결과 종류에 공통으로 적용되는 성과 또는 위험 지표의 의미, 계산 기준,
  단위, 계산 불가 조건, 우수 방향과 버전이다. 기존 결과 분석 및 가상투자 지표 정의를 참조한다.
- **랭킹 변경 기록(Ranking Change Record)**: 정정, 무효화, 공개 철회 또는 기준 개정이 어느 산정에 어떤
  영향을 주었는지 추적하는 정보다. 공개 철회된 내용은 권한 있는 감사 범위에서만 유지한다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 동일 랭킹에 포함된 결과의 100%가 결과 종류, 시장·대상 범위, 평가 기간, 초기·실행 조건,
  데이터 기준과 지표 정의 버전의 비교 가능성 검사를 통과한다.
- **SC-002**: 백테스트와 가상투자, 서로 다른 평가 기간 또는 서로 다른 지표 정의 버전의 결과가 같은 순위에
  포함된 사례가 0건이다.
- **SC-003**: 랭킹 산정의 100%에서 지표 이름·정의 버전·단위·우수 방향, 공통 비교 조건, 포함·제외 기준,
  동률 규칙, 산정 마감 시점과 적격 항목 수를 사용자가 확인할 수 있다.
- **SC-004**: 랭킹 목록의 순위 기준값과 공개 상세의 같은 지표 값이 불일치한 사례가 0건이며, 모든 값에서
  원본 결과와 산정 시점을 추적할 수 있다.
- **SC-005**: 소유자의 명시적 공개 동의 없이 비공개 전략·결과·사용자 정보가 랭킹 후보, 순위, 항목 수 또는
  상세에 노출된 사례가 0건이다.
- **SC-006**: 공개 철회 후 사용자의 다음 접근부터 해당 결과가 현재 랭킹이나 공개 상세에 제공된 사례가
  0건이며, 이후 산정에 다시 포함된 사례도 0건이다.
- **SC-007**: 동일한 결과 집합, 비교 조건, 지표 정의, 산정 마감 시점과 동률 규칙으로 검증한 랭킹의 100%가
  동일한 순위와 기준값을 재현한다.
- **SC-008**: 공개 적격 결과가 10,000개인 랭킹 조회의 95%에서 사용자는 3초 이내에 첫 순위 목록, 기준
  요약과 마지막 산정 시점을 확인한다.
- **SC-009**: 사용성 검증에서 대상 사용자의 90% 이상이 2분 이내에 원하는 결과 종류·기간·지표의 랭킹을
  찾고 상위 항목의 수익과 위험 정보를 함께 확인할 수 있다.
- **SC-010**: 사용성 검증에서 대상 사용자의 85% 이상이 서로 다른 결과가 같은 랭킹에 포함되거나 제외된
  이유, 순위 지표의 우수 방향과 과거 순위가 미래 수익 보장이 아니라는 점을 추가 도움 없이 설명할 수 있다.
- **SC-011**: 결과 소유자의 90% 이상이 2분 이내에 공개될 필드를 확인해 특정 결과의 랭킹 참여에 동의하고,
  참여 상태를 확인한 뒤 철회할 수 있다.

## Assumptions

- 랭킹 조회 대상은 인증된 Thorp 사용자이며, 랭킹 참여 결과의 공개 범위는 인증된 사용자에게
  제공되는 랭킹 목록과 상세로 한정한다. 외부 검색 노출이나 익명 공개 링크는 포함하지 않는다.
- 백테스트 전략 랭킹은 성공 완료된 결과를, 가상투자 랭킹은 공통 평가 기간까지 확정된 성과 스냅샷을
  사용한다. 두 결과 종류는 항상 별도 랭킹으로 제공한다.
- “동일한 비교 기준”에는 결과 종류, 시장·대상 범위, 정확한 평가 기간, 초기 자산과 실행 조건, 데이터 기준,
  지표 정의 버전이 포함된다. 전략과 파라미터는 비교 대상이므로 항목별로 다를 수 있다.
- 순위 지표는 기존 공통 성과지표 중 우수 방향이 정의된 항목에서 선택한다. 총수익률과 최대 낙폭은 각 항목에
  함께 표시하는 최소 성과·위험 정보이며 다른 공통 지표도 상세에서 제공한다.
- 가상투자 결과는 시작 시점이 아니라 동일한 달력상 평가 기간의 완전한 관측값으로 비교한다. 기간 전체를
  포함하지 못하는 실행을 기간 길이가 같다는 이유만으로 함께 비교하지 않는다.
- 공개 주체는 사용자가 서비스에서 공개하도록 설정한 표시 이름으로 구분한다. 실제 신원 정보는 랭킹 공개에
  필요하지 않으며 별도 동의 없이 노출하지 않는다.
- 랭킹 참여 동의는 전략 저장·공유 동의와 독립적이다. 동의를 위해 필요한 공개 결과 스냅샷 생성은 F11에
  포함하지만 저장 전략의 소유·공유·리비전 정책 자체는 F9 범위로 유지한다.
- 결과의 공개 동의를 철회해도 공정성 확인에 필요한 최소 감사 기록은 권한 있는 범위에서 보존한다. 일반
  사용자에게는 철회된 항목의 전략·성과·소유자 정보를 과거 산정 상세로 다시 제공하지 않는다.
- 랭킹은 일정한 산정 시점의 결과 스냅샷으로 제공되며 갱신 주기 자체는 계획 단계에서 정한다. 사용자는 항상
  마지막 산정 시점과 평가 마감 시점을 확인할 수 있다.
- 랭킹 계산 방식, 저장소, 갱신 작업과 대량 처리 기술은 계획 단계에서 SC-008의 실제 부하를 측정한 뒤
  결정한다. 미래 확장만을 이유로 특정 기술을 먼저 선택하지 않는다.

## Constitution Alignment

- **원칙 I·II (독립 실행과 추적성)**: F11은 백테스트·가상투자를 직접 실행하지 않고 확정 결과를 소비한다.
  FR-007·FR-027·FR-028이 각 랭킹 산정의 식별·재현·변경 추적을 요구하며 산정 실행 구조는 정하지 않는다.
- **원칙 III (실측 후 기술 도입)**: FR-031은 구체적인 저장·배치·분산 기술을 제외한다. SC-008의 규모와
  응답 목표를 실제 측정해 현재 요구를 만족하는 구조를 계획한다.
- **원칙 IV (파트 경계 계약)**: 랭킹 정의·산정·항목, 공개 결과와 동의 상태는 결과 생산 기능과 랭킹 소비
  기능이 공유할 계약이다. 필드와 호환성은 계획 단계에서 문서화하고 함께 변경한다.
- **원칙 V (신뢰성과 비교 가능성)**: FR-003~FR-015가 동일한 조건·데이터·지표 정의와 투명한 우수 방향을,
  FR-027~FR-028이 재현성과 변경 추적을 요구한다. 비교 불가능한 결과나 계산 불가 값을 순위에 섞지 않는다.
- **보안·데이터 제약**: FR-018~FR-026은 비공개 기본값, 결과별 명시적 동의, 최소 공개 범위, 철회와 권한
  검사를 요구하며 공개 정보에 비밀값을 포함하지 않는다.
- 원칙에서 벗어나는 요구사항은 없다.
