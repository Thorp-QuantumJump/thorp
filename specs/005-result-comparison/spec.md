## 범위 요약

전략 진단의 세 번째 단계다. 결과 첫 화면을 핵심 숫자 3개·비교 그래프 1개·해석 요약 1문장으로 구성하고, 같은 조건의 두 결과를 비교하며, 상세 근거는 결과 근처의 '자세히 보기'에서 연다. 결과 의미를 바꾸는 상태는 결과 옆 한 문장으로 표시하고, 추천·승자·확률로 읽힐 표현은 만들지 않는다. (§4.2.3)

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 결과 첫 화면에서 핵심을 바로 이해한다 (Priority: P1)

[전략을 검증하려는 개인]은 많은 지표를 읽지 않고 결과의 핵심을 파악하기 위하여 결과 첫 화면에서 비용 차감 후 전체 수익률·가장 크게 줄었던 폭·거래비용과 비교 그래프 1개, 계산으로 확인된 차이 1문장, 분석 조건 한 줄을 볼 수 있다. (§4.1, §4.2.3, D10)

**Why this priority**: 첫 화면 단순함은 기획서가 정한 가장 중요한 설계 원칙이다(§2). 결과를 이해하지 못하면 진단이 성립하지 않는다.

**Independent Test**: 완료된 분석 하나를 열어 첫 화면에 정확히 숫자 3개·그래프 1개·문장 1개·조건 한 줄이 있고 그 외 상세가 접혀 있는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 분석이 완료된 상태에서, **When** 결과를 열면, **Then** 첫 화면에 비용 차감 후 전체 수익률·가장 크게 줄었던 폭·거래비용 세 숫자와 비교 그래프 1개, 해석 요약 1문장이 보인다.
2. **Given** 결과 첫 화면에서, **Then** 분석 기간·비교 대상·비용 적용 여부가 요약 한 줄에 항상 보인다.
3. **Given** '가장 크게 줄었던 폭'을 보면, **Then** 그것이 운용 중 고점 대비 최대 하락이며 시작 금액 대비 손실과 다르다는 설명이 함께 있다.
4. **Given** 결과 첫 화면에서, **Then** 해석 요약 문장은 계산으로 확인된 차이만 말하고 추천이나 원인 단정을 담지 않는다.
5. **Given** 자동 배분 전략의 결과이면, **Then** 표시된 비중이 선택한 규칙의 계산 결과라는 표시가 있고 사용자가 입력한 비중과 구분된다.

### User Story 2 - 같은 조건에서 두 결과를 비교한다 (Priority: P1)

[전략을 검증하려는 개인]은 전략이나 설정의 차이가 결과에 어떤 영향을 줬는지 보기 위하여 사용자 고정 비중·동일 비중을 기준으로 두고 다섯 전략 중 다른 결과를 골라 같은 조건의 두 결과를 한 그래프에서 비교할 수 있다. (§4.2.3, D10)

**Why this priority**: 비교는 제품의 중심 약속이다(D01). 조건이 다른 결과를 나열하면 가정의 차이를 측정하게 된다(원칙 IV).

**Independent Test**: '내가 정한 비중'을 기준으로 두고 '흐름을 따라 배분하기' 결과를 비교 대상으로 골라 그래프에 두 결과가 같은 기간·금액·비용으로 그려지는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 결과 화면에서, **Then** 비교 기준은 사용자 고정 비중 또는 동일 비중으로 기본 유지되고, 비교 대상은 다섯 전략 중 다른 결과나 자동 탐색에서 고른 후보로 바꿀 수 있다.
2. **Given** 두 결과를 비교하면, **Then** 그래프에는 최대 두 결과가 동시에 그려지고 두 결과는 같은 섹터 후보 집합·평가 날짜·금액·비용·정보 이용 기준을 쓴다.
3. **Given** 비교 대상의 실제 보유 섹터가 기준과 달라졌으면, **When** 상세를 열면, **Then** 선정 효과와 배분 효과를 함께 설명한다.
4. **Given** 기본 설정 비교와 자동 탐색 후보 비교는, **Then** 화면에서 구분되어 표시된다.
5. **Given** 어느 비교에서도, **Then** 후보마다 유리한 과거 기간을 달리 쓰지 않으며 같은 평가 기간이 강제된다.

### User Story 3 - 상세 근거를 결과 근처에서 찾는다 (Priority: P2)

[전략을 검증하려는 개인]은 결과 차이의 원인과 취약 조건을 이해하기 위하여 결과 근처의 '자세히 보기'에서 손실이 커진 때·회복 기간·회전율·상관관계·위험 기여·구성종목 중복·거래 내역·비용 가정·비교 규칙·대표 ETF 구성·출처를 확인하고, '손실이 커진 때 보기'와 '다른 조건으로 비교'로 다음 분석에 이어갈 수 있다. (§4.1, §4.2.3, D10)

**Why this priority**: 상세 근거를 스스로 찾을 수 있는지가 사용성 확인 질문 중 하나다(§7.2). 첫 화면 단순함을 유지하면서 근거를 제공하는 층이다.

**Independent Test**: 결과에서 '자세히 보기'를 열어 항목이 모두 있는지, 설정 화면으로 되돌아가지 않는지, '다른 조건으로 비교'가 조건이 채워진 설정 화면으로 이어지는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 결과 첫 화면에서, **When** '자세히 보기'를 누르면, **Then** 설정 화면으로 되돌아가지 않고 결과 근처에서 상세 패널이 열린다.
2. **Given** 상세 패널에서, **Then** 회복 기간·회전율·상관관계·위험 기여(추정 기간·산정법 포함)·구성종목 중복·전체 거래 내역·비용 가정·비교 규칙·대표 ETF 구성·출처가 있다.
3. **Given** 위험 기여 추정에 필요한 자료가 짧거나 불안정하면, **Then** 그 항목에 계산 제한이 표시되고 값이 0이나 임의 값으로 대체되지 않는다.
4. **Given** 결과 화면에서, **When** '손실이 커진 때 보기'를 누르면, **Then** 손실이 커진 구간이 강조되고 그 구간의 보유·거래·비용을 볼 수 있다.
5. **Given** 결과 화면에서, **When** '다른 조건으로 비교'를 누르면, **Then** 현재 조건이 채워진 전략 선택 화면이 열리고 분석하면 새 분석으로 저장된다.

### User Story 4 - 결과의 상태와 한계를 결과 옆에서 본다 (Priority: P2)

[전략을 검증하려는 개인]은 결과를 과신하지 않기 위하여 '탐색 결과 / 미사용 검증 결과 / 미검증' 구분과 자료 부족·계산 제한·부분 완료 같은 상태를 해당 결과 옆 한 문장으로 볼 수 있다. (§4.1, §4.2.3, §7.3, D11)

**Why this priority**: 결과 의미를 바꾸는 상태를 상세에만 숨기면 오해가 생기고, 모든 화면에 경고를 늘리면 첫 화면 단순함이 깨진다. 둘 사이의 규칙이 필요하다(원칙 II·VI·VII).

**Independent Test**: 자료가 부족한 섹터를 포함한 분석과 자동 탐색에서 고른 후보를 열어 결과 옆에 상태 문장이 있는지, 경고가 목록으로 늘어나지 않는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 자료 부족·근거 부족·계산 제한·부분 완료가 있는 결과에서, **Then** 해당 결과 옆에 한 문장으로 표시되고 상세 안에만 숨겨지지 않는다.
2. **Given** 자동 탐색에서 고른 후보의 결과에서, **Then** '탐색 결과 / 미사용 검증 결과 / 미검증' 중 해당 상태가 결과 옆에 구분 표시된다.
3. **Given** 내부 검증이 끝나지 않은 항목이 있어도, **Then** 결과 의미를 바꾸지 않는 항목은 경고 목록으로 나열되지 않는다.
4. **Given** 결과 화면에서, **Then** 종료 시 시가평가 결과와 청산 비용 포함 결과가 구분된다.

---

### User Story 5 - 보조 보기와 다음 탐색으로 이어간다 (Priority: P3)

[전략을 검증하려는 개인]은 결과를 다른 관점에서 확인하기 위하여 광범위 국내 주가지수와의 비교와 목표 위험을 맞춘 분석을 보조 보기로 열고, '경제환경이 비슷했던 과거 보기'로 같은 섹터·전략·설정을 유지한 채 이어갈 수 있다. (§4.2.3, §4.3, D10, D25)

**Why this priority**: 보조 보기와 경제환경 연결은 진단을 확장하는 기능이며 첫 화면의 필수 요소가 아니다.

**Independent Test**: 결과에서 지수 비교 보조 보기를 열어 참고 정보로 표시되는지, '경제환경이 비슷했던 과거 보기'가 기존 조건을 유지한 채 열리는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 결과 화면에서, **When** 지수 비교 보조 보기를 열면, **Then** 광범위 국내 주가지수와의 비교가 참고 정보로 표시되고 기본 비교 기준을 바꾸지 않는다.
2. **Given** 결과 화면에서, **When** 목표 위험 맞춤 보기를 열면, **Then** 별도 시나리오임이 표시되고 자료가 불안정하면 계산 제한이 표시된다.
3. **Given** 결과 화면에서, **When** '경제환경이 비슷했던 과거 보기'를 누르면, **Then** 기존 섹터·전략·설정이 유지된 채 [011](../011-regime-strategy-link/spec.md)의 화면이 열린다.

---

### Edge Cases

- 비교 대상 결과가 아직 계산 중이면 그래프에는 기준만 그리고 비교 대상 자리에 진행 상태를 보인다.
- 두 결과의 공통 평가 기간이 다르면(예: 나중에 추가한 전략의 워밍업이 더 길 때) 공통 구간으로 맞춰 다시 계산하도록 안내하고, 다른 기간을 한 그래프에 겹쳐 그리지 않는다.
- 자료 부족으로 어느 결과의 일부 구간이 비어 있으면 그 구간을 빈 채로 표시하고 보간하지 않는다.
- 전체 수익률과 최대 하락 폭이 모두 0인 결과(예: 전 기간 현금 대기)는 그 사실을 한 문장으로 설명하고 좋은 결과로 표시하지 않는다.
- 거래 내역이 매우 길면 상세 패널 안에서 기간·종목으로 좁혀 볼 수 있고 첫 화면에는 나열하지 않는다.
- 사용성 관찰에서 첫 결과의 핵심을 이해하려면 여러 상세 패널을 열어야 한다고 드러나면 요약 화면을 수정한다. 반대로 결과 의미를 바꾸는 자료 부족이 상세에만 있었다면 결과 옆 한 문장으로 올린다. (§7.2)

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 결과 첫 화면은 핵심 숫자 3개(비용 차감 후 전체 수익률·가장 크게 줄었던 폭·거래비용), 비교 그래프 1개, 해석 요약 1문장으로 구성한다. (§4.1, §4.2.3)
- **FR-002**: '가장 크게 줄었던 폭'은 운용 중 고점 대비 최대 하락으로 정의하고, 시작 금액 대비 손실과 혼동하지 않게 설명을 붙인다. (§4.2.3)
- **FR-003**: 분석 기간·비교 대상·비용 적용 여부를 요약 한 줄에 항상 표시한다. (§4.1)
- **FR-004**: 비교 그래프는 최대 두 결과를 동시에 그린다. 기본 비교 기준은 사용자 고정 비중 또는 동일 비중이며, 비교 대상은 다섯 전략 중 다른 결과나 자동 탐색에서 고른 후보로 바꿀 수 있다. (§4.2.3, D10)
- **FR-005**: 비교하는 두 결과는 같은 섹터 후보 집합·평가 날짜·금액·비용·정보 이용 기준을 쓴다. 후보마다 유리한 과거 기간을 달리 쓰지 않으며, 기간이 다르면 겹쳐 그리지 않고 공통 구간으로 다시 계산하도록 안내한다. (§4.2.3, §6.4.1, 원칙 IV)
- **FR-006**: 해석 요약 1문장은 계산으로 확인된 차이만 설명한다. 추천·원인 단정·확률 표현을 담지 않는다. (§4.2.3, 원칙 III)
- **FR-007**: '자세히 보기'는 결과 근처에 두고 설정 화면으로 되돌리지 않는다. 상세 패널에는 회복 기간·회전율·상관관계·위험 기여(추정 기간·공분산 산정법 포함)·구성종목 중복·전체 거래 내역·비용 가정·비교 규칙·대표 ETF 구성·출처를 둔다. (§4.1, §4.2.3)
- **FR-008**: 비교 대상의 실제 보유 섹터가 기준과 달라졌으면 상세에서 선정 효과와 배분 효과를 함께 설명한다. (§4.2.3, D10)
- **FR-009**: 자료가 짧거나 불안정해 계산이 제한된 상세 항목은 계산 제한을 표시하고 0이나 임의 값으로 대체하지 않는다. (§4.2.3, 원칙 VI)
- **FR-010**: '손실이 커진 때 보기'는 손실이 커진 구간을 강조하고 그 구간의 보유·거래·비용을 보인다. '다른 조건으로 비교'는 현재 조건이 채워진 [003](../003-strategy-settings/spec.md) 화면으로 이어지고, 분석하면 새 분석으로 저장된다. (§4.2.3, §5)
- **FR-011**: 기본 설정 비교와 자동 탐색에서 선택한 후보 비교를 구분해 표시한다. 자동 탐색 후보의 안정성·선정 이유·탈락 사유·전체 후보는 [007](../007-auto-parameter-search/spec.md)의 상세에서 본다. (§4.2.3)
- **FR-012**: 결과 옆에 '탐색 결과 / 미사용 검증 결과 / 미검증'을 구분 표시한다. 탐색에 사용한 성과와 미사용 기간 성과를 섞지 않는다. (§4.2.3, §7.3, D11)
- **FR-013**: 결과 의미를 바꾸는 자료 부족·근거 부족·계산 제한·부분 완료는 해당 결과 옆에 한 문장으로 표시하고 상세 안에만 숨기지 않는다. 결과 의미를 바꾸지 않는 내부 검증 미완료는 경고 목록으로 늘리지 않는다. (§4.1, §7.2, §7.4)
- **FR-014**: 자동 배분 전략의 출력 비중은 선택한 규칙의 계산 결과로 표시하고 사용자 입력 비중과 구분한다. (§4.2.1, D13)
- **FR-015**: 종료 시 시가평가 결과와 청산 비용 포함 결과를 구분해 표시한다. (§6.4.1)
- **FR-016**: '추천 비중', 주문 버튼, 자동 단일 승자, 일·주·월간 우승 전략, 사용자 간 성과 랭킹, 확률로 읽힐 표현('87% 유사', '지금도 잘될 전략' 등)을 만들지 않는다. 한 항목 기준 정렬은 제공할 수 있다. (§4.2.3, D13, D16, 원칙 III)
- **FR-017**: 광범위 국내 주가지수와의 비교와 목표 위험을 맞춘 분석은 보조 보기로 제공한다. 지수 비교는 참고 정보이며 기본 비교 기준을 바꾸지 않고, 목표 위험 맞춤은 별도 시나리오로 표시한다. (§4.2.3, §6.4.1)
- **FR-018**: '경제환경이 비슷했던 과거 보기' 진입점을 제공한다. 진입 시 기존 섹터·전략·설정을 유지해 [011](../011-regime-strategy-link/spec.md)로 넘긴다. (§4.3, D25)
- **FR-019**: 결과는 완료 시 [006 내 기록](../006-my-records/spec.md)에 보존되고, 결과 화면에서 '설정 바꿔 비교'와 내보내기 진입점을 제공한다. (§5)
- **FR-020**: KRX 자료를 쓰는 결과 화면에 '한국거래소 통계정보' 출처를 표시한다. 정보는 세 층(바로 보이는 정보 / 요청하면 펼치는 정보 / 시스템이 처리하는 정보)으로 배치하고 내부 계산 항목을 동시에 나열하지 않는다. (§4.1, §6.2)

### Key Entities *(include if feature involves data)*

- **결과 요약 카드**: 핵심 숫자 3개와 정의 설명, 조건 한 줄, 해석 요약 1문장이다.
- **비교 뷰**: 기준 결과·비교 대상 결과·그래프·공통 조건(섹터 후보·기간·금액·비용·정보 이용 기준)·비교 종류(기본 설정 / 자동 탐색 후보)다.
- **상세 패널 항목**: FR-007의 항목과 각 항목의 계산 제한 상태다.
- **결과 상태 표시**: 검증 구분(탐색/미사용 검증/미검증), 자료 부족·계산 제한·부분 완료 문장이다.
- **보조 보기**: 지수 비교, 목표 위험 맞춤과 그 시나리오 표시다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 결과 첫 화면에 보이는 요소는 핵심 숫자 3개·그래프 1개·요약 1문장·조건 한 줄이며 그 외 상세는 요청해야 열린다.
- **SC-002**: 사용성 관찰(전략을 검증하려는 개인 6~8명)에서 참여자가 상세 패널을 열지 않고 세 숫자의 의미, 특히 고점 대비 최대 하락과 시작 금액 대비 손실의 차이를 구분하는지 기록한다. 두 명 이상이 같은 지점에서 오해하면 요약 화면을 수정한다. (§7.2, D20)
- **SC-003**: 한 그래프에 그려진 두 결과의 섹터 후보 집합·평가 기간·금액·비용·정보 이용 기준이 다른 사례가 0건이다.
- **SC-004**: 추천 비중·주문·단일 승자·우승 전략·랭킹·확률 표현이 결과 화면에 0건이다.
- **SC-005**: 결과 의미를 바꾸는 자료 부족·계산 제한이 상세 안에만 숨겨진 사례가 0건이다.
- **SC-006**: '자세히 보기'가 설정 화면으로 되돌린 사례가 0건이다.
- **SC-007**: 참여자가 진행자의 도움 없이 상세 근거(손실이 커진 때, 거래 내역, 비용 가정)를 찾는지 기록한다.

## Assumptions

- 결과 값과 상세 지표는 [004](../004-backtest-execution/spec.md)가 산출한 것을 그대로 표시한다. 이 spec은 값을 계산하지 않는다.
- 광범위 국내 주가지수 자료는 [001](../001-etf-market-data/spec.md)이 확보한 KOSPI 시리즈다.
- 검증 구분(탐색/미사용 검증/미검증) 판정 기준은 PD-12에서 정하며, 확정 전 모든 결과는 '미검증'으로 표시한다.
- 한국어 웹 화면이며 데스크톱 브라우저를 우선한다.

## Pre-Implementation Decisions *(팀 확정 필요)*

이 spec이 직접 소유하는 결정 항목은 없다. PD-12(검증 설계, 소유: [007](../007-auto-parameter-search/spec.md))의 판정 기준과 PD-14(사용성 관찰, README)에 의존한다.
