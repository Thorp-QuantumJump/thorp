# B06 검증 기록

**기준일**: 2026-09-18 · **병합 기준**: `origin/dev` `da929d3f` · **티켓**: [S15P21E205-302](https://ssafy.atlassian.net/browse/S15P21E205-302)

T073·T074·T076·T077·T078을 완료했다. **T075는 부분 수행**이며 아래 남은 수동 확인을 끝내기 전에는 B06 완료로 표시하지 않는다. 원래 작업 디렉터리의 미커밋 변경을 제외한 별도 worktree에서 확인했다.

## 환경과 자료

- Windows, Java 21, Node.js·npm, Docker Desktop. PostgreSQL 16 전용 임시 DB에 Flyway를 적용했다.
- `local` 프로필에서 `SPRING_FLYWAY_ENABLED=true`, `SPRING_JPA_HIBERNATE_DDL_AUTO=validate`, `SPRING_SESSION_JDBC_INITIALIZE_SCHEMA=never`를 사용했다.
- 관리 허용 계정 하나와 일반 계정 하나, 두 섹터의 합성 대응표 `FIXTURE-B06`, 검증용 글만 넣었다. 운영 원고·운영 권한 설정은 확인하지 않았다.
- 브라우저는 실제 Vite → Spring Boot → PostgreSQL 경로를 사용했다. HTTP 확인도 응답 대역 없이 실제 로그인 세션·CSRF로 실행했다.
- 가격 시계열은 넣지 않았다. 따라서 003의 공통 평가기간 계산과 분석 실행 성공은 이 결과에 포함하지 않는다.
