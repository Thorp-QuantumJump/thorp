## 환경과 자료

- Windows, Java 21, Node.js, Docker Desktop의 로컬 PostgreSQL에 **합성 자료 전용 DB** `thorp_b15`를 새로 만들고 Flyway로 마이그레이션을 적용했다(§0의 명령, `THORP_LEARNING_ADMIN_USER_IDS=1`). 운영 DB와 운영 원고는 쓰지 않았다.
