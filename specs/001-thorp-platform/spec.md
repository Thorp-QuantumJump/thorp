## 범위 요약

이 spec은 기획서 §8.1 "현재 개발할 것" 다섯 항목 전체를 하나의 기능 범위로 다룬다.

1. 대표 ETF·공통 자료·전략별 파라미터 명세를 정하고 다섯 배분 전략(고정 비중·동일 비중·역변동성·섹터 모멘텀·최소분산)의 계산과 재현을 완성한다.
2. '섹터 선택 → 전략·최소 설정 확인 → 결과 비교' 흐름과 상세 설정·내 기록을 연결한다.
3. 자동 파라미터 대량 탐색('설정 조합 자동 비교')을 구현한다.
4. 전략 엔진과 별도로 경제환경 검색(분야별 기본·선택형 Thorp 종합 비교)을 구현하고 사례 식별자·평가 날짜·내 기록으로 전략 진단과 연결한다.
5. 시장 흐름·뉴스·독립 학습 페이지를 병행 구현하고 사용성을 점검한다.

우선순위는 constitution 원칙 I(중심 약속은 전략 진단)에 따라 전략 진단 흐름(P1) → 결과 상세·자동 탐색·내 기록(P2) → 경제환경 탐색과 전략 연결(P3) → 뉴스·배우기(P4) 순이다. 경제환경 검색은 자동 탐색 완료 뒤에만 착수하는 종속 작업이 아니며(§8.1), 우선순위는 병렬 개발을 막지 않는다.

기획서가 "실행 전 결정 항목"으로 남긴 값은 이 문서에서 확정하지 않고 아래 "Pre-Implementation Decisions" 표에 결정 항목으로 표시한다. 기획서가 확정한 경제환경 모델 v1 기본값은 그대로 적용하고, 변경은 새 모델 버전으로만 제안한다.

## User Scenarios & Testing *(mandatory)*

사용자 스토리는 Jira Story 형식 `[대상]은 (목적)하기 위하여 (활동/작업/기능)할 수 있다`로 쓴다. 대상은 기획서 §3.2의 세 사용자(전략을 검증하려는 개인 / 거시경제·뉴스 관심 사용자 / 완전 입문자) 중 하나다.

### User Story 1 - 섹터·비중을 정해 고정 비중과 동일 비중을 같은 조건으로 비교한다 (Priority: P1)

[전략을 검증하려는 개인]은 자신이 정한 섹터 비중이 과거에 어떤 수익·손실·비용을 냈는지 이해하기 위하여 섹터와 비중을 정하고 '내가 정한 비중'과 '똑같이 나누기'를 같은 조건으로 비교 분석할 수 있다. (§3.1, §4.2.1, §4.2.3, D03, D04, D10)

**Why this priority**: 전략 진단은 제품의 중심 약속이며(D01), 고정 비중과 동일 비중은 모든 후속 비교의 기준이다(D10). 이 스토리 하나만 구현해도 "섹터 선택 → 분석 → 결과 이해"라는 최소 제품이 성립한다.

**Independent Test**: 섹터 2개 이상을 선택하고 비중을 입력한 뒤 '분석하기'를 눌러 결과 첫 화면(핵심 숫자 3개·비교 그래프 1개·해석 요약 1문장)이 나오는지 확인한다. 다른 전략·자동 탐색·경제환경 기능 없이 단독으로 검증할 수 있다.

**Acceptance Scenarios**:

1. **Given** 섹터 목록의 각 항목에 섹터 이름과 대표 ETF 이름이 함께 보이는 상태에서, **When** 사용자가 섹터 3개를 선택하면, **Then** 동일 비중이 자동으로 채워지고 이 초깃값이 입력 편의를 위한 예시라는 표시가 보인다.
2. **Given** 비중을 직접 수정해 합계가 100%가 아닌 상태에서, **When** 입력을 마치면, **Then** 그 위치에 남은 비중이 표시되고 '동일하게 나누기'로 되돌릴 수 있으며 시스템이 비중을 임의로 바꾸지 않는다.
3. **Given** 섹터·비중을 확정한 상태에서, **When** '분석하기'를 누르면, **Then** 요청이 즉시 접수되어 진행 상태가 보이고, 완료 후 첫 화면에 비용 차감 후 전체 수익률·가장 크게 줄었던 폭·거래비용과 비교 그래프 1개, 계산으로 확인된 차이 1문장, 분석 기간·비교 대상·비용 적용 여부 한 줄이 보인다.
4. **Given** 결과 첫 화면에서, **When** 비교 그래프를 보면, **Then** '내가 정한 비중'과 '똑같이 나누기' 두 결과가 같은 섹터 후보 집합·평가 기간·금액·비용·정보 이용 기준으로 동시에 그려진다.
5. **Given** 선택한 섹터 중 대표 ETF가 없거나 워밍업 자료가 부족한 섹터가 있을 때, **When** 섹터를 선택하면, **Then** 선택 단계에서 한 문장으로 안내하고 사용자에게 데이터 입력을 요구하지 않는다.
6. **Given** 후보 중 긴 관측 기간 때문에 공통 평가 구간이 줄어드는 상태에서, **When** 분석을 시작하려 하면, **Then** 실행 전에 줄어든 구간을 알린다.

### User Story 2 - 역변동성·섹터 모멘텀·최소분산을 선택하고 상세 설정을 조정한다 (Priority: P1)

[전략을 검증하려는 개인]은 비중을 직접 정하는 방식과 규칙 기반 배분 방식의 차이를 비교하기 위하여 '변동성에 따라 나누기'·'흐름을 따라 배분하기'·'전체 변동성을 줄이도록 배분하기' 중 하나를 선택하고 필요하면 그 전략에 해당하는 상세 설정만 조정할 수 있다. (§4.2.2, §6.4.2, D04)

**Why this priority**: 다섯 전략은 기획서가 현재 범위로 확정한 핵심이며(D04, D17), 사용자의 질문 "직접 정한 비중과 강한 섹터를 따라가거나 변동성을 줄이는 방식은 어떤 차이가 나는가"(§3.1)에 답하려면 세 규칙 전략이 필요하다.

**Independent Test**: 전략 카드에서 세 규칙 전략을 각각 선택해 기본 설정으로 분석하고, 상세 설정을 열어 허용 범위 안에서 값을 바꾼 뒤 다시 분석해 결과가 달라지는지 확인한다. User Story 1의 화면 흐름 위에서 검증한다.

**Acceptance Scenarios**:

1. **Given** 전략 카드 5개가 쉬운 이름과 한 줄 설명만으로 보이는 상태에서, **When** 카드 하나를 선택하면, **Then** 기본 화면에는 전략과 '기본 설정 사용'만 보인다.
2. **Given** 전략을 선택한 상태에서, **When** '상세 설정'을 열면, **Then** 그 전략에 해당하는 항목만 열리고 각 항목의 의미·허용 범위·기본값 복원이 제공되며 기본값이 편의용 출발점이라는 표시가 있다.
3. **Given** '흐름을 따라 배분하기'를 선택한 상태에서, **When** 분석이 끝나면, **Then** 출력 비중이 선택한 규칙의 계산 결과라고 명시되고 사용자가 입력한 비중과 구분되며, 선정 대상 없음·동점이 발생한 시점은 등록된 규칙대로 처리되고 상세에 기록된다.
4. **Given** '전체 변동성을 줄이도록 배분하기'를 선택하고 추정 불안정 또는 해 없음이 발생한 상태에서, **When** 결과를 보면, **Then** 등록된 처리 규칙이 적용되고 결과 옆에 계산 제한이 한 문장으로 표시되며 0이나 확신 있는 요약으로 대체되지 않는다.
5. **Given** 상세 설정에서 허용 범위 밖 값을 입력하면, **When** 저장하려 하면, **Then** 허용 범위를 안내하고 값을 몰래 잘라 넣지 않는다.

### User Story 3 - 결과의 근거를 상세에서 확인한다 (Priority: P2)

[전략을 검증하려는 개인]은 결과 차이의 원인과 취약 조건을 이해하기 위하여 결과 근처의 '자세히 보기'에서 손실이 커진 때·회복 기간·회전율·상관관계·위험 기여·구성종목 중복·거래 내역·비용 가정·대표 ETF 구성·출처를 확인할 수 있다. (§4.1, §4.2.3, D10, D13)

**Why this priority**: 첫 화면은 단순해야 하지만(원칙 II) 사용자가 상세 근거를 스스로 찾을 수 있어야 한다(§7.2). 결과 화면이 있어야 붙일 수 있으므로 P1 다음이다.

**Independent Test**: 완료한 분석 결과에서 '자세히 보기'를 열어 각 상세 항목이 설정 화면으로 돌아가지 않고 결과 근처에서 열리는지, 자료가 짧은 항목에 계산 제한이 표시되는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 결과 첫 화면에서, **When** '자세히 보기'를 누르면, **Then** 설정 화면으로 되돌아가지 않고 결과 근처에서 상세 패널이 열린다.
2. **Given** 자동 배분 전략의 실제 보유 섹터가 사용자의 후보 집합과 달라진 상태에서, **When** 상세를 보면, **Then** 선정 효과와 배분 효과를 함께 설명한다.
3. **Given** 위험 기여 추정에 필요한 자료가 짧거나 불안정한 상태에서, **When** 상세를 보면, **Then** 추정 기간·공분산 산정법과 함께 계산 제한이 표시된다.
4. **Given** 결과 화면에서, **When** '손실이 커진 때 보기' 또는 '다른 조건으로 비교'를 누르면, **Then** 그 조건이 반영된 다음 분석으로 이어진다.
5. **Given** KRX 자료를 사용한 화면이면, **Then** '한국거래소 통계정보' 출처가 표시된다.

### User Story 4 - 설정 조합을 자동으로 비교한다 (Priority: P2)

[전략을 검증하려는 개인]은 설정을 하나씩 바꿔 반복 계산하지 않고 유리하거나 불리한 설정 범위를 파악하기 위하여 '설정 조합 자동 비교'를 한 동작으로 실행하고 소수 후보의 수익·큰 손실·비용을 비교할 수 있다. (§4.2.2, §6.4.3, D04, D10, D18, D19)

**Why this priority**: 기획서 §8.1 세 번째 항목이며 전략 진단 위에서 동작한다. 실행 한도·기록 규칙이 함께 필요하므로 P1 이후에 둔다.

**Independent Test**: 전략군과 섹터 후보 집합을 고정한 뒤 자동 비교를 실행해 실행 전 확인 화면, 유효성 위반 조합의 사전 제외, 부분 완료 처리, 결과의 후보 비교와 상태 표시를 확인한다.

**Acceptance Scenarios**:

1. **Given** 전략군과 섹터 후보 집합을 고정한 상태에서, **When** '설정 조합 자동 비교'를 선택하면, **Then** 실행 전에 대상 전략·탐색 범위 요약·예상 작업량·적용 한도를 간단히 확인하며 후보 숫자를 직접 입력하라고 요구하지 않는다.
2. **Given** 등록된 조합 중 유효성 제약을 위반하는 조합(모멘텀 선정 수가 가용 섹터 수를 넘는 경우, 비중 상한들의 합계로 투자 비중을 채울 수 없는 경우)이 있을 때, **When** 실행하면, **Then** 그 조합은 계산 전에 제외되고 제외 사유가 기록된다.
3. **Given** 실행 중인 탐색에서, **When** 사용자가 취소하거나 한도에 도달하면, **Then** 부분 결과임을 알리고 완료한 범위를 명시한다.
4. **Given** 탐색이 완료된 상태에서, **When** 결과를 보면, **Then** 소수 후보의 수익·큰 손실·비용이 먼저 보이고 인접 설정 안정성·선정 이유·탈락 사유·전체 후보는 상세에서 보이며 자동 단일 승자나 투자 추천으로 표시되지 않는다.
5. **Given** 탐색 결과에서, **Then** 각 후보 옆에 '탐색 결과 / 미사용 검증 결과 / 미검증' 중 해당 상태가 구분 표시된다.
6. **Given** 탐색 설정에서, **Then** 수수료·세금·평가 기간은 탐색 변수로 제공되지 않는다.

### User Story 5 - 완료한 분석을 내 기록에서 다시 열고 조건을 바꿔 비교한다 (Priority: P2)

[전략을 검증하려는 개인]은 이전 분석과 같은 조건을 재현하고 조건 변경의 영향을 비교하기 위하여 '내 기록'에서 완료한 분석을 이름·섹터·전략·분석 기간·저장일로 찾아 다시 보고 '설정 바꿔 비교'로 새 분석을 만들 수 있다. (§5, D14, D15)

**Why this priority**: 기록은 결과 해석의 근거이며 재현성의 전제다(D14). 분석이 존재해야 기록할 수 있으므로 P1 이후다.

**Independent Test**: 분석을 두 번 완료한 뒤 내 기록 목록에서 각각을 다시 열어 동일 결과가 보이는지, '설정 바꿔 비교'가 새 분석을 만들고 기존 결과를 덮어쓰지 않는지, 내보내기가 동작하는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 완료한 분석이 있을 때, **When** 내 기록을 열면, **Then** 이름·섹터·전략·분석 기간·저장일로 구분된 목록이 보인다.
2. **Given** 목록에서 분석 하나를 선택하고, **When** '다시 보기'를 누르면, **Then** 저장된 동일 버전의 결과가 재계산 없이 보인다.
3. **Given** 다시 본 분석에서, **When** '설정 바꿔 비교'를 누르고 분석하면, **Then** 새 분석으로 저장되고 기존 결과는 덮어쓰이지 않는다.
4. **Given** 자동 탐색 결과가 있을 때, **When** 내 기록을 보면, **Then** 한 묶음으로 보이고 펼치면 후보별 결과·선정 이유·실패 또는 제외 사유가 보인다.
5. **Given** 기록 항목에서, **When** 추가 메뉴의 내보내기를 누르면, **Then** CSV 또는 JSON으로 받을 수 있고 원천 시세·기사는 자료별 이용 범위 안에서만 포함된다.
6. **Given** 어느 화면에서도, **Then** 사용자에게 버전이나 실험 ID 입력을 요구하지 않는다.

### User Story 6 - 전략 없이 분야별 경제환경을 본다 (Priority: P3)

[거시경제·뉴스 관심 사용자]는 전략을 정하지 않고도 현재 경제환경을 분야별로 파악하기 위하여 '시장 흐름'에서 7개 분야의 변화 요약을 보고 관심 분야를 열어 개별 지표의 실제 값·단위·최근 3개월 경로를 확인할 수 있다. (§4.4, D07, D08, D12, D22)

**Why this priority**: 거시경제·뉴스 관심 사용자의 진입 화면이다(D02). 전략 진단과 독립적으로 개발하며(§8.1), 중심 약속인 진단 뒤에 둔다.

**Independent Test**: 시장 흐름 화면에서 7개 분야와 변화 요약이 보이고, 분야를 열면 지표별 실제 값·단위·최근 3개월 경로와 기준월이 보이는지 확인한다. 전략 진단 기능 없이 검증할 수 있다.

**Acceptance Scenarios**:

1. **Given** 시장 흐름에 진입하면, **Then** 생산·소비/투자·대외거래·노동·물가/원자재·금융/주택·해외 경기 7개 분야 이름과 짧은 변화 요약이 보이고 경제 전체를 하나의 좋고 나쁜 점수로 요약한 표시는 없다.
2. **Given** 관심 분야를 열면, **Then** 그 분야 지표들의 실제 값·단위·최근 3개월 경로와 '비슷했던 때 보기', 그리고 그 분야의 기준월(T_g)이 보이며 최신 개정자료를 이용한 역사 비교라는 표시가 있다.
3. **Given** 지표 자료가 오래됐거나 수집이 실패한 상태에서, **Then** 마지막 갱신 시각이 보이고 실시간 정보라고 표시하지 않는다.
4. **Given** 어느 화면에서도, **Then** 거시경제 API나 자료 공급원의 이름을 사용자가 고르게 하지 않는다.
5. **Given** 사용자가 섹터를 선택해도, **Then** 경제환경 표시와 순위는 바뀌지 않고 연결할 전략·상품·뉴스의 범위만 좁혀진다.

### User Story 7 - 분야 기준으로 경제환경이 비슷했던 과거를 찾는다 (Priority: P3)

[거시경제·뉴스 관심 사용자]는 지금과 비슷한 경제환경이 언제였는지 알기 위하여 관심 분야의 '비슷했던 때 보기'에서 거리순 사례를 처음 3개(더 보기로 최대 10개)까지 관측 구간·비슷한 점·다른 점과 함께 확인할 수 있다. (§4.3, §6.4.4, D08, D09, D21, D24)

**Why this priority**: 경제환경 검색의 기본 모드다(D08). 시장 흐름(User Story 6)의 지표 자료 위에서 동작한다.

**Independent Test**: 분야 하나를 골라 검색을 실행하고 모델 v1 규칙(공통 척도·거리·후보 제한)대로 정렬되는지, 처음 3개·최대 10개가 보이며 후보가 부족하면 채우지 않는지, 문턱 교정 전 '최근접 참고 사례' 상태가 표시되는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 분야 g와 기준월 T_g가 정해진 상태에서, **When** '비슷했던 때 보기'를 누르면, **Then** 모델 v1 규칙(공통 척도, 3개월 시점별 절댓값 차이 평균, 12개월 초과 이전 후보, ±6개월 건너뛰기, 동률은 오래된 월 우선)으로 정렬된 사례가 처음 3개 보인다.
2. **Given** 처음 3개가 보이는 상태에서, **When** '더 보기'를 누르면, **Then** 최대 10개까지 보이고 후보가 부족하면 부족한 대로 보인다.
3. **Given** 유사성 문턱이 교정되기 전이면, **Then** 사례는 '최근접 참고 사례'로 표시되고 검색 상태는 '가까운 순서만 제공·유사성 미판정'이며 '87% 유사'·'지금도 잘될 전략' 같은 확률·추천 표현이 없다.
4. **Given** 각 사례에서, **Then** 관측 구간(3개월)·비슷한 점·다른 점이 먼저 보이고 이후 63거래일 시장 결과는 별도 영역에, 21거래일 결과·거리·기여도·자료 기준은 상세에 있다.
5. **Given** 어느 지표의 MAD가 0이면, **Then** IQR 기반 대체 척도를 쓰고, 그것도 0이면 그 지표가 속한 분야(종합이면 종합)의 검색 상태를 '계산 불가'로 표시하며 임의 epsilon이나 묵시적 클리핑으로 순위를 만들지 않는다.
6. **Given** 사용자가 과거 기준월을 지정하면, **Then** 그 월이 유지되고 화면에 항상 표시된다.

### User Story 8 - Thorp 종합 비교를 선택해서 연다 (Priority: P3)

[거시경제·뉴스 관심 사용자]는 여러 분야를 함께 놓고 과거를 비교하기 위하여 'Thorp 종합 비교'를 선택해 7개 분야 거리를 같은 비중으로 결합한 사례와 분야별 차이를 함께 볼 수 있다. (§4.3, §4.4, §6.4.4, D08, D22, D23)

**Why this priority**: 분야별 검색이 기본이고 종합은 선택형이다(D08). 분야별 검색(User Story 7)을 확장한다.

**Independent Test**: 분야 보기에서 종합 비교를 열어 기준월이 T_all로 바뀔 때 알림이 보이는지, 종합 사례에 분야별 거리와 기여도가 함께 보이는지, 교정 후 충족 사례가 없을 때 분야별 탐색으로 연결되는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 분야 보기 상태에서, **When** 'Thorp 종합 비교'를 선택하면, **Then** 종합 보기가 열리고 기준월이 17개 지표의 공통 최신월 T_all로 바뀌며 T_g와 다르면 "전체 분야를 맞추기 위해 비교 기준월이 바뀝니다"라고 한 문장으로 알린다.
2. **Given** 종합 사례에서, **Then** 7개 분야 거리의 동일가중 평균과 분야별 거리·기여도가 함께 보이고 '노동과 건설은 가깝지만 수출은 다릅니다'처럼 닮은 점과 차이를 함께 설명한다.
3. **Given** 종합 사례 안에서 분야별 설명을 보면, **Then** 기준월은 T_all로 유지되고 분야별 최신 질의값이 섞이지 않으며 더 최신인 개별 발표는 별도 정보로 표시된다.
4. **Given** 유사성 기준이 교정된 뒤 충족 사례가 없으면, **Then** "설정된 종합 유사성 기준을 충족하는 사례가 없습니다. 분야별로 살펴볼 수 있습니다"라는 안내와 함께 분야별 탐색으로 연결되고 미충족 참고 사례는 별도로 열 수 있다.
5. **Given** 종합 비교 화면에서, **Then** 동일가중이 Thorp의 설계 선택이라는 표시가 있고 "모든 지표의 중요성이 같다"는 표현은 없다.

### User Story 9 - 경제환경 사례에서 전략 비교로 이어진다 (Priority: P3)

[전략을 검증하려는 개인]은 비슷한 경제환경 이후 자신의 전략이 어떻게 행동했는지 이해하기 위하여 선택한 사례의 사후 구간에서 후보 전략들의 보유 섹터·비중, 거래와 비용, 손실 기여를 같은 조건으로 비교하고 전체 기간 결과와 함께 볼 수 있다. (§4.3, §6.4.4, D06, D25, D26)

**Why this priority**: 경제환경 탐색과 전략 진단을 하나의 이용 흐름으로 연결하는 가치다(D17, D25). 두 기능이 모두 있어야 한다.

**Independent Test**: 시장 흐름에서 사례를 골라 '이 기간으로 전략 비교'로 진단을 시작하고, 반대로 진단 결과에서 '경제환경이 비슷했던 과거 보기'로 들어가 기존 섹터·전략·설정이 유지되는지, 전략을 바꿔도 사례 순위가 같은지, 자료가 부족한 전략 결과만 제한되는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 시장 흐름에서 사례를 선택한 상태에서, **When** '이 기간으로 전략 비교'를 누르면, **Then** 섹터와 전략을 정한 뒤 그 사례의 관측 종료 후 첫 거래일부터 63거래일 사후 구간의 전략 결과가 연결된다.
2. **Given** 진단 결과에서 '경제환경이 비슷했던 과거 보기'로 진입하면, **Then** 기존 섹터·전략·설정이 유지되고, 검색 범위는 비교 묶음의 모든 전략이 평가 가능한 ETF 이력·가장 긴 워밍업·사후 자료의 공통 가용 범위가 기본이며 '선택 ETF로 비교 가능한 기간'과 제외 수가 표시되고 전체 경제환경 탐색으로 전환할 수 있다.
3. **Given** 같은 기준월·분야·자료/모델 버전·가용 후보 집합에서, **When** 비교 전략을 바꾸면, **Then** 경제환경 사례 순위는 바뀌지 않는다.
4. **Given** 선택한 사례에서 어느 전략의 ETF가 미상장이거나 워밍업이 부족하거나 사후 자료가 미완성이면, **Then** 사례는 그대로 유지되고 그 전략 결과만 '자료 부족'으로 표시되며 다른 사례로 조용히 대체되지 않는다.
5. **Given** 사례의 전략 결과에서, **Then** 전체 기간 연속 운용 결과의 해당 사후 구간이 기본으로 보이고, 그날 현금으로 새로 시작하는 결과는 별도 시나리오로 구분되며, 기간이 다른 거래량은 월당 거래횟수·회전율 같은 척도로 비교된다.
6. **Given** 사례의 전략 결과에서, **Then** KOSPI는 순위 확정 뒤 참고 정보로만 붙고, 경제환경의 유사성이 수익의 원인이라고 단정하는 문구가 없으며, 최신 개정자료를 이용한 역사 탐색이라는 표시가 있다.
7. **Given** 비교 묶음에 전략을 추가해 공통 가용 범위가 달라지면, **Then** 한 문장으로 알리고 유지율과 변경 내용을 보이며 별도 검색으로 기록한다.

### User Story 10 - 시장 흐름에서 뉴스 묶음을 본다 (Priority: P4)

[거시경제·뉴스 관심 사용자]는 경제환경 변화의 맥락을 파악하기 위하여 시장 흐름에서 주요 뉴스 묶음 3개를 제목·매체·발행 시각·짧은 사실 요약·원문 링크로 보고 섹터를 선택해 관련 뉴스로 좁힐 수 있다. (§4.4, §6.3, D12)

**Why this priority**: 뉴스는 해석의 맥락이며 중심 기능이 아니다(원칙 I). 매체 허가 확인(§10.1)이 공개 전 조건이므로 마지막 묶음에 둔다.

**Independent Test**: 시장 흐름에서 뉴스 묶음 3개가 보이고 각 항목의 필드가 채워져 있는지, 기사 본문이 저장·표시되지 않는지, 수집 실패 시 마지막 갱신 시각이 보이는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 시장 흐름에 진입하면, **Then** 주요 뉴스 묶음 3개가 보이고 같은 사건의 중복 보도는 한 묶음으로 정리되어 있다.
2. **Given** 뉴스 항목에서, **Then** 제목·매체·발행 시각·짧은 사실 요약·원문 링크만 보이고 기사 본문은 저장되거나 표시되지 않는다.
3. **Given** 뉴스 수집이 실패했거나 지연된 상태에서, **Then** 마지막 갱신 시각이 보이고 빈 뉴스는 오류가 아닌 정상 화면으로 처리된다.
4. **Given** 과거 경제환경 사례를 보는 화면에서, **Then** 그 당시 발행된 뉴스만 연결되고 현재 뉴스와 구분된다.
5. **Given** 사용자가 섹터를 선택하면, **Then** 그 섹터·기업·경제 주제와 연결된 뉴스로 좁혀진다.

### User Story 11 - 배우기에서 예시를 익히고 바로 진단으로 이동한다 (Priority: P4)

[완전 입문자]는 전략 진단을 시작하기 전에 필요한 개념을 익히기 위하여 '배우기'의 주제별 글(질문 하나·예시 하나)을 읽고 '이 예시로 비중 비교하기'로 예시가 채워진 진단을 바로 시작할 수 있다. (§4.5, D01, D02)

**Why this priority**: 입문자가 진단을 시작하도록 돕는 보조 기능이다(원칙 I). 진단 화면이 있어야 연결할 수 있다.

**Independent Test**: 배우기 목록에서 주제 하나를 열어 질문·예시·연결 버튼이 있는지, 연결 버튼이 예시 섹터·비중이 채워진 진단 화면으로 이동하는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 배우기에 진입하면, **Then** '섹터와 ETF'·'비중과 리밸런싱'·'백테스트'·'수익과 손실'·'과거가 미래를 보장하지 않는 이유'를 포함한 주제 목록이 블로그 글 형식의 커리큘럼으로 보인다.
2. **Given** 주제 하나를 열면, **Then** 한 가지 질문과 한 가지 예시를 중심으로 짧은 설명이 보이고 '이 예시로 비중 비교하기' 연결이 있다.
3. **Given** '이 예시로 비중 비교하기'를 누르면, **Then** 예시의 섹터·비중이 채워진 전략 진단 화면으로 이동한다.
4. **Given** 진단 화면의 용어 도움말을 열면, **Then** 배우기와 같은 설명이 재사용된다.
5. **Given** 어느 진입 경로에서도, **Then** 진단 전에 학습 수강을 요구하지 않는다.

### Edge Cases

- 비중 합계가 100%가 아니면 그 위치에 남은 비중을 표시하고 '동일하게 나누기'를 제공한다. 시스템이 비중을 임의로 바꾸지 않는다. (§4.2.1)
- 선택 섹터에 대표 ETF가 없거나 선택 전략의 워밍업 자료가 부족하면 선택 단계에서 한 문장으로 안내한다. (§4.2.1)
- 후보 중 긴 관측 기간 때문에 공통 평가 구간이 줄면 실행 전에 알린다. (§6.4.1)
- 섹터 모멘텀에서 선정 대상이 없거나 동점이면 등록된 규칙(현금 대기 등)대로 처리하고 상세에 기록한다. 규칙 자체는 결정 항목이다. (§6.4.2)
- 최소분산에서 추정 불안정·해 없음·0 변동성이 발생하면 등록된 처리 규칙을 적용하고 계산 제한을 표시한다. (§6.4.2)
- 자동 탐색에서 유효성 위반 조합은 계산 전에 제외하고 제외 사유를 남긴다. 취소·한도 도달 시 부분 결과임을 알린다. (§6.4.3, §6.5)
- 경제환경 검색에서 어느 지표의 MAD가 0이면 IQR 기반 대체 척도를 쓰고, 그것도 0이면 해당 분야·종합을 '계산 불가'로 제한한다. 임의 epsilon·묵시적 클리핑·지표 몰래 제외를 하지 않는다. (§6.4.4, D27, U06)
- 경제환경 후보가 3개 미만이면 채우지 않고 부족한 대로 보인다. 12개월 이내 종료월은 제외하고, 선택한 종료월 ±6개월은 건너뛴다. 정확한 동률은 오래된 월을 우선한다. (§6.4.4, D09)
- 기준 자료가 60개월 미만이면 공통 척도를 계산할 수 없으므로 검색 상태를 '계산 불가/후보 없음'으로 표시한다. 과거 후보 자체의 시대별 이력이 부족하면 보조 설명만 제한한다. (§6.4.4, D21)
- 분야 보기에서 종합으로 전환해 기준월이 바뀌면 한 문장으로 알리고 별도 검색으로 기록한다. (§4.4, D22)
- 선택 사례에서 ETF 미상장·워밍업 부족·사후 미완성이면 사례를 유지하고 해당 전략 결과만 '자료 부족'으로 표시한다. (§4.3, D26)
- 전략 결과 경로의 공통 가용 범위 검색 결과가 비어 있으면 빈 결과를 정상 처리하고 전체 탐색 전환을 제공한다. 합성 ETF 이력이나 임의 대체로 채우지 않는다. (U05)
- 뉴스 수집이 실패하거나 지연되면 마지막 갱신 시각을 보이고 빈 뉴스를 정상 화면으로 처리한다. (§4.4)
- 계산 실패는 낮은 수익과 구분해 기록·표시한다. 결과를 만들 수 없을 때 0이나 확신 있는 요약으로 대체하지 않는다. (§7.1)
- 동일 버전(설정·데이터 마감/버전·비용·엔진·모델·검색 설정)을 재실행하면 같은 결과가 나온다. (§7.1)
- 인증키 발급 전이거나 자료를 이용할 수 없으면 허용된 대체 자료·명시된 예시 자료로 개발하고 자료 부족은 해당 결과에만 표시한다. (§6.1, §10.1)

## Requirements *(mandatory)*

### Functional Requirements

#### 공통 화면 원칙 (§4.1, 원칙 II)

- **FR-001**: 시스템은 주요 메뉴 '전략 진단 / 시장 흐름 / 배우기'와 보조 메뉴 '내 기록'을 제공하고, 처음 진입한 사용자가 전략 진단을 바로 시작할 수 있게 한다.
- **FR-002**: 화면마다 가장 중요한 행동 버튼을 하나만 둔다. 시작 화면은 '비중 비교하기', 입력 완료 후에는 '분석하기'다.
- **FR-003**: 결과 첫 화면은 핵심 숫자 3개(비용 차감 후 전체 수익률·가장 크게 줄었던 폭·거래비용), 비교 그래프 1개, 해석 요약 1문장으로 구성하고, 분석 기간·비교 대상·비용 적용 여부를 요약 한 줄에 항상 표시한다.
- **FR-004**: 결과 의미를 바꾸는 자료 부족·근거 부족·미판정 상태는 해당 결과 옆에 한 문장으로 표시하고 상세 안에만 숨기지 않는다. 내부 검증 미완료를 모든 화면의 경고 목록으로 늘리지 않는다.
- **FR-005**: 계산식·자료 공급원 선택·거리 함수·실험 식별자·서버/인프라 설정을 사용자 기본 입력으로 요구하지 않는다.
- **FR-006**: 정보를 세 층(처음에 바로 보이는 정보 / 요청하면 펼쳐 보는 정보 / 시스템이 처리하는 정보)으로 배치하고 내부 계산 항목을 화면에 동시에 나열하지 않는다. 처음에 보이는 정보는 선택 섹터·비중, 적용 ETF 이름, 분석 기간, 배분 방식, 핵심 결과와 필요한 한 줄 안내다.
- **FR-007**: 시작 절차로 고객군 선택 설문·숙련도 분류·사전 학습 수강을 요구하지 않는다.
- **FR-008**: '자세히 보기'는 결과 근처에 두고, 상세 정보를 보기 위해 설정 화면으로 되돌려 보내지 않는다.

#### 섹터와 비중 (§3.3, §4.2.1, D03)

- **FR-010**: 섹터 목록의 각 항목은 섹터 이름과 대표 ETF 이름을 함께 표시한다. 대표 ETF는 국내 주식에 투자하는 국내 상장 비레버리지·비인버스 ETF 중에서 서비스가 미리 관리하며, 목록·기준 지수·공통 기간은 결정 항목이다.
- **FR-011**: 섹터를 선택하면 동일 비중을 초깃값으로 채우고, 이 값이 입력 편의를 위한 예시이며 투자 권고가 아님을 표시한다. 사용자는 비중을 직접 수정할 수 있다.
- **FR-012**: 비중 합계가 맞지 않으면 그 위치에 남은 비중을 표시하고 '동일하게 나누기'로 되돌릴 수 있게 한다. 사용자 비중을 임의로 바꾼 뒤 알리지 않는 처리를 하지 않는다.
- **FR-013**: 대표 ETF가 없거나 선택 전략의 워밍업 자료가 부족한 섹터는 선택 단계에서 한 문장으로 안내한다.
- **FR-014**: 자동 배분 전략에서 선택 섹터는 투자 후보 집합이며 매번 모두 보유한다는 뜻이 아님을 표시한다. 사용자가 입력한 비중은 고정 비중 전략과 비교 기준에 쓰고 자동 전략의 출력 비중과 구분한다.
- **FR-015**: '대표 상품 정보'(요청 시 펼치는 정보)에서 지수 방법론·구성종목 중복·상장일·유동성·추적 차이와 현재 생존 상품만 고른 결과의 한계를 표시한다. 과거 구성 이력이 없으면 현재 구성 기준 진단과 과거 운용 결과를 구분해 표시한다.
- **FR-016**: 업종과 테마를 구분하고, 대표 ETF의 실제 상장 이후 기간으로만 비교한다. 상장 전 지수 성과를 본 결과에 혼합하지 않는다.

#### 전략과 설정 (§4.2.2, §6.4.2, D04)

- **FR-020**: 선택한 섹터 후보 집합에 대해 아래 다섯 전략을 카드로 제공한다. 카드에는 화면 이름과 한 줄 설명만 둔다.

  | 화면 이름 | 전략 | 한 줄 설명 | 상세 설정 항목 |
  |---|---|---|---|
  | 내가 정한 비중 | 고정 목표 비중 | 지정한 비중으로 주기적으로 맞춘다. | 목표 비중·리밸런싱 주기·비중 상한 |
  | 똑같이 나누기 | 동일 비중 | 선택 섹터에 같은 목표 비중을 둔다. | 리밸런싱 주기·투자 가능 섹터와 제약 |
  | 변동성에 따라 나누기 | 역변동성 | 최근 변동성이 낮은 섹터에 더 큰 비중을 둔다. | 변동성 관측 기간·리밸런싱 주기·비중 상한 |
  | 흐름을 따라 배분하기 | 섹터 모멘텀 | 과거 성과의 방향 또는 상대 강도를 규칙으로 삼아 섹터를 선택·배분한다. | 관측 기간·최근 구간 제외 여부·선정 수 또는 임계값·배분 방식·리밸런싱 주기 |
  | 전체 변동성을 줄이도록 배분하기 | 최소분산 | 섹터들이 함께 움직이는 정도를 반영해 추정 포트폴리오 분산이 작아지는 비중을 계산한다. | 공분산 관측 기간·추정 방법·비중 상한·리밸런싱 주기 |

- **FR-021**: 기본 화면에서는 전략과 '기본 설정 사용'만 확인한다. '상세 설정'은 선택한 전략에 해당하는 항목만 열고 각 항목의 의미·허용 범위·기본값 복원을 제공한다.
- **FR-022**: 기본값·초깃값은 편의용 출발점으로 표기하고 최적값이나 투자 권고로 표기하지 않는다.
- **FR-023**: 공통 출발 설정은 월말 리밸런싱과 역변동성 63거래일 관측이다. 이 값은 출발안이며 승인된 후보 범위 안에서 변경·탐색할 수 있다.
- **FR-024**: 전략별로 의미가 있는 설정만 허용하고, 후보 값·범위·간격·유효성 제약·기본값을 실행 전에 등록한다. 등록되지 않은 값은 입력·실행할 수 없다.
- **FR-025**: 섹터 모멘텀은 '당시 이용 가능한 수익률 관측 → 점수 계산 → 섹터 선정 → 선정 섹터 배분 → 다음 거래일 체결' 순서로 동작한다. 상대 모멘텀(섹터 간 순위)과 절대 모멘텀(자기 과거 수익의 임계값)은 다른 규칙으로 구분한다. 사용할 유형·점수 산식·관측 길이·최근 구간 제외·선정 수/임계값·선정 후 배분(동일/역변동성)·동점·선정 대상 없음·현금 대기 규칙은 결정 항목이며 결정 뒤 버전으로 기록한다.
- **FR-026**: 최소분산은 추정 공분산에 대해 포트폴리오 분산을 최소화하는 비중을 비음수·비중 상한·사전 고정한 투자 비중 합계 제약 아래 계산한다. 투자 비중 합계를 고정해 전액 현금이라는 자명한 해로 끝나지 않게 하고, 거래 후 정수 수량의 잔여 현금은 별도로 처리한다. 관측 기간·표본/축소 공분산 추정 방법·추정 불안정·수치 오차·해 없음 처리와 해법은 결정 항목이다. 추정 분산 최소화를 미래 손실 최소 보장으로 표현하지 않는다.
- **FR-027**: 모든 전략에 비중 상한·현금·추정 불가·실행 불가능한 제약의 처리 규칙을 적용하고, 0 변동성·선정 대상 없음·추정 실패를 처리한다.
- **FR-028**: 분석 기간은 비교 후보가 공통으로 평가 가능한 범위에서 자동 제시한다. 금액·비용은 '기간·금액·조건'에서 확인·변경한다. 수수료·세금·평가 기간은 수익을 높이는 방향으로 자동 최적화하는 변수가 아니다.
- **FR-029**: 후보 중 긴 관측 기간 때문에 공통 평가 구간이 줄면 실행 전에 사용자에게 알린다.

#### 분석 실행과 한도 (§4.2.2, §6.5, D18, D19)

- **FR-030**: '분석하기' 요청은 즉시 접수되고 사용자는 대기·실행·완료·실패 상태를 조회할 수 있다.
- **FR-031**: 분석 이후 진행 표시·취소·재시도·동일 결과 재사용을 제공한다. 동일 버전 조회와 새 계산을 구분한다.
- **FR-032**: 한도 초과·부분 완료·제약 위반은 이유를 짧게 알리고 완료한 범위를 명시한다.
- **FR-033**: 동일 버전(전략·파라미터·섹터/ETF 대응·데이터 마감/버전·평가 분할·비용·엔진·검색 설정)의 재실행은 같은 결과를 낸다. 이 항목들이 동일 결과 식별의 기준이다.
- **FR-034**: 후보 수·실행시간·대기열·메모리 상한은 실측 후 고정한다. 상한을 정하기 전에는 무제한 탐색을 열지 않으며, 초기 임시 상한은 결정 항목이다.
- **FR-035**: 전략 단일 실행·자동 탐색 묶음·분야별 및 종합 경제환경 검색을 구분해 대기 포함 응답 시간 분포(중앙값·95백분위)·동시 처리량·자원 사용·실패·건당 원가를 측정하고 기록한다.
- **FR-036**: 계산·데이터·저장 원가와 동일 결과 재조회를 구분해 기록한다. 진단 화면에 포인트·상품 선택·결제 단계를 넣지 않는다.
- **FR-037**: 사용자에게 서버·인프라 설정을 요구하거나 노출하지 않는다.

#### 계산 공통 규칙 (§6.1, §6.4.1, D05, D06)

- **FR-040**: 신호와 리밸런싱 판단은 판단 시점까지 이용 가능한 자료로만 하고, 가상 체결은 그 다음 거래일에 한다.
- **FR-041**: 공매도·레버리지 없이 정수 수량·잔여 현금·거래 불가·비용을 처리한다.
- **FR-042**: 원시 가격은 체결에, 기업행위를 일관되게 반영한 자료는 신호·성과에 사용한다. 분배금과 ETF 내부 보수를 중복 반영하지 않는다.
- **FR-043**: 상장 전 합성 이력이나 미래 자료로 빈 값을 채우지 않는다.
- **FR-044**: 포트폴리오 하나는 공유 현금·비중을 가진 한 실행 단위다. 내부 섹터를 독립 자본처럼 병렬 합산하지 않는다.
- **FR-045**: 주 분석은 전체 가용 기간 연속 운용이다. 신규 현금 시작·비용 상승·목표 위험 맞춤은 별도 시나리오로 구분한다.
- **FR-046**: 종료 시 시가평가 결과와 청산 비용을 포함한 결과를 구분해 표시한다.
- **FR-047**: 후보 중 가장 긴 관측 기간과 최근 제외 구간을 감안한 공통 워밍업을 확보하고, 워밍업 구간은 성과에서 제외한다.
- **FR-048**: 수수료·호가 차이·슬리피지·세금·비용 상승 조건은 결정한 뒤 버전으로 기록한다. 구체 수치는 결정 항목이다.
- **FR-049**: 가격과 기업행위 처리가 불명확한 상품·기간은 분석 범위를 줄이고 해당 결과에 '자료 부족'을 표시한다.

#### 결과 이해와 비교 (§4.2.3, D10, D13)

- **FR-050**: '가장 크게 줄었던 폭'은 운용 중 고점 대비 최대 하락으로 정의하고, 시작 금액 대비 손실과 혼동하지 않게 설명을 붙인다.
- **FR-051**: 비교 그래프는 선택한 전략·설정과 비교 기준, 최대 두 결과를 동시에 보인다. 사용자 고정 비중·동일 비중을 기본 비교 기준으로 유지하고 다섯 방식 중 다른 결과를 비교 대상으로 선택할 수 있다.
- **FR-052**: 비교는 같은 섹터 후보 집합·같은 평가 날짜·같은 금액·같은 비용·같은 정보 이용 기준으로만 한다. 후보마다 유리한 과거 기간을 달리 선택하지 않는다.
- **FR-053**: 그래프 아래 한 문장은 계산으로 확인된 차이만 설명한다.
- **FR-054**: 기본 설정 비교와 자동 탐색에서 선택한 후보 비교를 구분한다. 실제 보유 섹터가 달라졌다면 상세에서 선정 효과와 배분 효과를 함께 설명한다.
- **FR-055**: '손실이 커진 때 보기'와 '다른 조건으로 비교'로 다음 분석에 이어진다.
- **FR-056**: 상세 패널에 회복 기간·회전율·상관관계·위험 기여(추정 기간·공분산 산정법 포함)·구성종목 중복·전체 거래 내역·비용 가정·비교 규칙·출처를 둔다. 자료가 짧거나 불안정하면 계산 제한을 표시한다.
- **FR-057**: 광범위 국내 주가지수와의 비교와 목표 위험을 맞춘 분석은 보조 보기로 제공한다.
- **FR-058**: 결과 옆에 '탐색 결과 / 미사용 검증 결과 / 미검증'을 구분 표시한다. 탐색에 사용한 성과와 미사용 기간 성과를 섞지 않는다.
- **FR-059**: '추천 비중', 주문 버튼, 자동 단일 승자, 일·주·월간 우승 전략, 사용자 간 성과 랭킹, 확률로 읽힐 유사도 표현을 만들지 않는다. 한 항목 정렬은 가능하다.

#### 자동 파라미터 대량 탐색 (§4.2.2, §6.4.3, D04, D10, D18, D19)

- **FR-060**: 사용자가 선택한 전략군·섹터 후보 집합을 고정한 뒤 사전 등록된 유효 파라미터 조합을 서버가 실행·비교한다. 무제한 전수 탐색이나 개인별 투자 추천으로 표현하지 않는다.
- **FR-061**: 실행 전에 대상 전략·탐색 범위 요약·예상 작업량·적용 한도를 간단히 확인한다. 모든 후보 숫자를 직접 입력하게 하지 않으며 상세 변경은 선택 사항이다.
- **FR-062**: 유효성 제약을 위반하는 조합(모멘텀 선정 수가 가용 섹터 수를 넘는 경우, 상한들의 합계로 투자 비중을 채울 수 없는 조합 등)은 계산 전에 제외하고 제외 사유를 기록한다.
- **FR-063**: 후보 선정은 비용 차감 성과·손실 제약·인접 설정 안정성에 대한 사전 기준을 사용한다. 구체 기준·동률 처리·표시 후보 수는 결정 항목이며 결과를 확인한 뒤 기준을 바꾸면 새 실험으로 기록한다.
- **FR-064**: 탐색 방법(그리드·무작위 등)·후보 수·실행시간·동시성 상한·중단 규칙은 결정 항목이다. 난수 기반 탐색은 시드를 저장한다.
- **FR-065**: 탐색 묶음별로 예상·유효·완료·실패·제외·미실행 후보 수를 관리하고 후보 실행 상태(완료/실패/제외/취소/미실행)를 기록한다.
- **FR-066**: 탐색 공간·실행한 전체 후보·미실행 후보 수·제외 사유·평가 분리·정렬 및 선정 규칙을 기록한다. 유효하지 않아 계산하지 않은 후보도 제외 사유를 남긴다.
- **FR-067**: 제약 위반·자료 부족·계산 실패를 낮은 수익과 구분해 기록·표시한다.
- **FR-068**: 전략 파라미터·경제환경 검색 설정·평가 시나리오는 별도 축으로 기록한다.
- **FR-069**: 자동 탐색에 기술적 사용량 상한과 원가 기록을 적용한다. 이는 결제 도입이 아니다.

#### 경제환경 검색 — 모델 v1 (§4.3, §4.4, §6.4.4, D07~D09, D21~D27)

- **FR-070**: 경제환경 입력 지표 17개를 아래 7개 분야에 고정한다. KDI 주요 경제지표 후보 18개 중 KOSPI는 사후 시장 정보로 분리한다.

  | 분야 | 입력 지표 | 변환 |
  |---|---|---|
  | 생산 | 전산업생산·광공업생산·서비스업생산 | 전년동월 대비 증가율 |
  | 소비·투자 | 소매판매액지수·설비투자지수·건설기성액(불변) | 전년동월 대비 증가율 |
  | 대외거래 | 수출·수입 / 무역수지 | 전년동월 대비 증가율 / 공식 금액 |
  | 노동 | 취업자 수 / 실업률 | 전년동월 대비 증가율 / 계절조정 비율 |
  | 물가·원자재 | 소비자물가 / 두바이유 | 전년동월 대비 증가율 / 월 평균 |
  | 금융·주택 | 국고채 3년·원/달러 환율 / 주택가격 | 월 기말 / 전월 대비 증가율 |
  | 해외 경기 | G20 경기선행지수 | 전년동월 대비 증가율 |

- **FR-071**: 지표 등록표에 지표별 원천·통계표·항목·단위·변환·발표 시점·개편 연결·결측 처리·작성기관·공표 정밀도를 기록하고 버전으로 관리한다. 통계표 코드 등 실제 값은 인증키 발급 후 확인해 채우는 결정 항목이다.
- **FR-072**: 지표 등록·분야 매핑·계산 가중은 화면 분류와 별도 버전으로 관리한다. 화면 이름이나 배치를 바꿨다는 이유로 계산 가중이 자동으로 바뀌지 않는다.
- **FR-073**: 기준월은 분야 검색이면 해당 분야 지표가 함께 확보된 최신월 T_g, 종합 검색이면 17개 지표가 함께 확보된 최신월 T_all, 사용자가 지정하면 그 과거 기준월이다. 비교 대상은 t-2·t-1·t 세 달이다. 모드를 바꾸어 t가 변하면 한 문장으로 알리고 별도 검색으로 기록한다. 대상월·발표일·자료 갱신 기준을 구분해 표시한다.
- **FR-074**: 공통 척도는 지표별로 현재 질의 구간 직전 t-122부터 t-3까지 최대 120개월(최소 60개월 연속 자료 필요)에서 중앙값 m과 산포 s를 구한다. s는 MAD에 정규분포 보정 상수(1/Φ⁻¹(0.75), 근사값 1.4826이며 구현은 정확한 분위수 값을 쓴다)를 곱한 값이다. MAD가 0이면 IQR을 정규분포 보정 상수(2×Φ⁻¹(0.75), 근사값 1.349)로 나눈 값을 쓰고, 그것도 0이면 계산 불가로 처리한다. IQR은 선형 보간의 75백분위와 25백분위 차이다. 질의와 모든 과거 후보에 같은 m·s를 적용한다.
- **FR-075**: 질의 기준 자료나 관측값의 결측을 임의 보간하지 않는다. 임의 epsilon을 넣거나 묵시적으로 클리핑해 순위를 만들지 않으며, 확인된 비정상 척도의 지표를 몰래 빼고 계산하지 않고 해당 지표가 속한 분야·종합 결과를 제한한다. 지표별 최소 유효 척도·예외 기준은 U06 결정 항목이다.
- **FR-076**: 기본 거리는 다음과 같다. 지표 i의 시점 k(1~3) 표준화 값 z = (x − m)/s, 지표 거리 E_i는 세 시점의 |z_A − z_B| 평균, d_i = E_i, 분야 거리 D_g는 분야 내 d_i의 산술평균, Thorp 종합 거리는 7개 D_g의 산술평균, 분야 기여도는 D_g를 7개 D_g 합으로 나눈 값이다. 전체 거리가 0이면 기여도를 표시하지 않는다. 움직임 항목의 추가 가중은 기본 모델에 넣지 않는다.
- **FR-077**: 분야 내부 지표 동일가중과 분야 간 1/7 동일가중을 초기 기본으로 쓰고, 이것이 Thorp의 설계 선택이며 경제적 중요성의 동일함이 아님을 표시한다. 지표·분야별 명목 비중과 실제 거리 기여를 기록한다.
- **FR-078**: 후보는 질의 종료월 t보다 12개월 초과 이전의 종료월만 허용한다. 분야 검색은 해당 분야 입력 3개월이 완전한 후보를 D_g로, 종합 검색은 7개 분야가 모두 유효한 후보를 Thorp 종합 거리로 정렬한다. 과거 후보 자체의 60개월 이력은 요구하지 않는다. 정확한 동률은 더 오래된 종료월을 우선한다. 선택된 종료월 주변 ±6개월은 건너뛴다. 처음 3개, '더 보기'로 최대 10개를 제공하며 억지로 채우지 않는다.
- **FR-079**: 검색 상태를 '계산 불가/후보 없음' / '가까운 순서만 제공·유사성 미판정' / '교정된 기준 충족 여부' 세 가지로 구분해 결과 옆에 표시한다. 유사성 문턱을 교정하기 전에는 사례를 '최근접 참고 사례'로 표시하고 '충분히 유사' 배지나 '대표 유사국면' 배지를 붙이지 않으며, 미교정이라는 이유로 '충분한 사례가 없다'고 단정하지 않는다. 교정 뒤 충족 사례가 없으면 분야별 탐색으로 연결하고 미충족 참고 사례는 별도로 열 수 있게 한다. 임계값·분야별 큰 차이 문턱은 U04 결정 항목이다.
- **FR-080**: 경제환경 후보는 선택 전략과 독립적으로 결정한다. 같은 기준월·분야·자료/모델 버전·가용 후보 집합에서는 전략을 바꿔도 순위가 바뀌지 않는다. 전략의 성과·수익·손실을 검색 입력이나 후보 선정에 쓰지 않는다.
- **FR-081**: 검색 경로를 두 가지로 구분한다. 시장 흐름 진입은 전체 거시 가용 사례를 대상으로 하며 ETF 이력으로 제한하지 않는다. 전략 결과 진입은 비교 묶음의 모든 전략이 평가 가능한 ETF 이력·가장 긴 워밍업·사후 자료의 공통 가용 범위를 기본으로 하고, '선택 ETF로 비교 가능한 기간'과 제외 수를 표시하며 전체 탐색으로 전환할 수 있다. 필터는 가용성에만 의존하고 별도 키로 보존하며, 두 경로의 순위·필터·연결 결과는 따로 보존한다. 전체 검색 순위를 조용히 대체하지 않는다.
- **FR-082**: 같은 비교 묶음에서는 같은 후보를 쓴다. 전략 추가로 가용 범위가 달라지면 알린 뒤 새 검색으로 기록한다. 기준월이나 검색 모드가 바뀌어 후보가 달라지면 유지율과 변경 내용을 보인다.
- **FR-083**: 사후 평가는 경제환경 관측 종료 후 첫 거래일부터 63거래일 주 평가와 21거래일 보조 평가다. 이는 역사 설명용 기준이며 실제 거시자료 발표 직후 매매를 재현한 것이 아님을 표시한다. 당시 의사결정 재현은 발표일·빈티지 이용 가능 시각 이후로 별도 정렬한다. 과거 가상 오늘에서 사후 성과를 참고할 때는 그 시점까지 평가가 완료된 사례만 쓴다.
- **FR-084**: 각 사례는 관측 구간(3개월)·비슷한 점·다른 점을 먼저 제시하고 이후 63거래일 시장·전략 결과를 별도 영역에 연결한다. 21거래일 결과·거리·기여도·자료 기준은 상세에 둔다. 현재 시장 상태는 지표의 말로 설명한다.
- **FR-085**: 사례에서 전략을 비교할 때 후보 전략 모두 같은 평가 날짜·비용을 쓰고, 보유 섹터·비중, 거래와 비용, 손실 기여를 같은 조건으로 보이며 전체 기간 결과와 함께 본다. 기본은 전체 기간 연속 운용 결과의 해당 사후 구간이며 그날 현금으로 새로 시작하는 결과는 별도 시나리오다. 기간이 다른 거래량은 월당 거래횟수·회전율 등 같은 척도로 비교한다.
- **FR-086**: 선택 사례에서 ETF 미상장·워밍업 부족·사후 미완성이면 사례를 유지하고 해당 전략 결과만 '자료 부족'으로 표시한다. KOSPI는 순위 확정 후 참고 정보로 붙인다.
- **FR-087**: 시대별 평소 대비 위치(각 후보 직전 최대 120·최소 60개월 기준)는 상세의 보조 설명으로만 제공하고 기본 순위와 결합하지 않는다. 해당 이력이 부족하면 보조 설명만 제한한다.
- **FR-088**: 움직임 추가 대안(0.7·E + 0.3·M), 시대별 척도 대안, 단순 가격 추세·변동성 검색(126/63거래일)은 내부 비교 기준으로만 유지하고 사용자 기본값·실제 영향 비율로 표시하지 않는다. 마할라노비스·PCA·RRF는 기본 모델에 넣지 않는다.
- **FR-089**: 거리·순위·유지율을 투자 성공 확률이나 확률적 신뢰도로 변환하지 않는다. 경제환경의 유사성이나 뉴스가 특정 전략 수익의 원인이라고 단정하지 않는다. 연속된 유사 날짜의 반복을 여러 독립 사례로 세지 않는다.
- **FR-090**: 최신 개정자료로 과거 경제환경을 비교하는 역사 탐색과 당시 공개 정보로 의사결정을 재현하는 분석을 구분하고, 화면에 어느 쪽인지 표시한다. 실제 발표일과 당시 발표·수정값을 확보하기 전에는 거시 검색을 매매 신호로 쓴 실시간 전략 검증을 주장하지 않는다.
- **FR-091**: 경제환경 검색 결과는 기준월·자료 버전·모델·분야 단위로 식별되어 전략 실행과 독립적으로 보존·재사용된다. 검색 결과와 전략 실행은 사례 식별자·평가 날짜로 연결한다.

#### 시장 흐름과 뉴스 (§4.4, §6.3, D12)

- **FR-100**: 시장 흐름 기본 화면은 7개 분야 이름과 짧은 변화 요약을 보이고, 관심 분야를 열면 개별 지표의 실제 값·단위·최근 3개월 경로와 '비슷했던 때 보기'를 제공한다. 경제를 하나의 경기 점수로 줄이지 않는다.
- **FR-101**: 국내 시장의 가격 추세·변동성은 별도 참고 정보로 표시한다.
- **FR-102**: 시장 흐름 기본 화면에 주요 뉴스 묶음 3개를 보인다. 뉴스 항목은 제목·매체·발행 시각·짧은 사실 요약·원문 링크를 제공하고, 같은 사건의 중복 보도는 한 묶음으로 정리한다.
- **FR-103**: 국내 경제 뉴스 RSS를 주 뉴스원으로, GDELT를 국제 사건·해외 보도의 보완원으로 쓴다. 기사 본문은 저장·재배포하지 않고 제목·매체·발행 시각·원문 링크만 다룬다. GDELT Tone은 비중·유사도 계산에 넣지 않는다.
- **FR-104**: 뉴스 1차 필터는 '기간 → 기사 관련성 → 중복 제거 → 필요한 필드 저장' 순서다. 국내 기사는 선택 섹터·기업·경제 주제와의 연결을 확인하고, 해외 기사는 국내 섹터와 연결되는 국제 주제로 제한한다. 두 경로를 합친 뒤 같은 원문을 가리키는 항목은 하나로 합치고 같은 사건의 보도는 한 묶음으로 정리한다.
- **FR-105**: 뉴스 기본 저장 항목은 원문 URL·매체·언어·발행 시각(확인 가능할 때)·수집 시각·관련 섹터/주제·중복 식별자다. GDELT 기록 시각을 기사 발행 시각으로 단정하지 않는다. 제목·요약은 확보한 정보에만 근거하고 확인할 수 없는 내용을 생성하지 않는다.
- **FR-106**: 자료가 오래됐거나 수집이 실패했으면 마지막 갱신 시각을 보이고, 데이터 제공 지연이 있는 항목을 실시간 정보라고 표시하지 않는다.
- **FR-107**: 섹터를 선택하면 해당 주제의 흐름과 뉴스로 좁힌다. 현재 뉴스와 과거 사건 설명을 구분하고 과거 사건에는 당시 발행된 뉴스만 연결한다.

#### 배우기 (§4.5, D01, D02)

- **FR-110**: 배우기는 주제별 커리큘럼(블로그 글 형식)이며 '섹터와 ETF', '비중과 리밸런싱', '백테스트', '수익과 손실', '과거가 미래를 보장하지 않는 이유'를 포함한다. 최종 주제 목록은 결정 항목이다.
- **FR-111**: 각 주제는 한 가지 질문과 한 가지 예시를 중심으로 구성하고 '이 예시로 비중 비교하기'로 예시가 채워진 진단에 연결한다.
- **FR-112**: 진단 화면의 용어 도움말은 배우기와 같은 설명을 재사용한다.
- **FR-113**: 숙련 퀀트 전용 연구 화면이나 자유 코드 입력을 만들지 않는다.

#### 내 기록과 재현 기록 (§5, D14, D15)

- **FR-120**: 내 기록은 완료한 분석을 이름·섹터·전략·분석 기간·저장일로 구분해 보이고, 기본 동작은 '다시 보기 / 설정 바꿔 비교'다. 상세 설정·거래 내역·내보내기는 추가 메뉴에서 접근한다.
- **FR-121**: 완료한 분석마다 전략·파라미터 범위·선정 기준·시드·평가 분할·섹터/ETF 대응·당시 대상·데이터 마감/버전·비용·엔진·검색 설정·사례 선정·원본 식별자를 저장한다.
- **FR-122**: 경제환경 탐색 기록에는 선택 분야 또는 종합 모드, 실제 질의 기준월(T_g/T_all 또는 지정월), 전체 후보와 표시 후보, 제외 이유, 지표 원값과 표준화 값, 분야별 거리, 자료 개정 기준, 모델 버전, 연결한 섹터·ETF·전략·사후 평가 구간, 당시 정보 재현 여부, ETF 가용성 필터를 저장한다.
- **FR-123**: 설정을 바꾸면 새 분석(새 버전)으로 보존하고 기존 결과를 덮어쓰지 않는다. 나중의 결과에 맞춰 과거 기준을 덮어쓰지 않는다.
- **FR-124**: 자동 탐색은 내 기록에서 한 묶음으로 보이고 펼치면 후보별 결과·선정 이유·실패 또는 제외 사유를 보인다.
- **FR-125**: 사용자에게 버전이나 실험 ID 입력을 요구하지 않는다.
- **FR-126**: CSV/JSON 내보내기를 제공한다. 원천 시세·기사의 내보내기는 자료별 이용 범위 안에서만 제공한다.
- **FR-127**: 시도·실패·최종 평가 열람 등 감사 정보는 내부에서 관리하고, 개인 식별정보는 계산 기록과 분리한다.
- **FR-128**: 보관 기간·삭제·연결 해제·공유 후 회수 정책·탐색 묶음 저장 상한은 결정 항목이며 무기한 보관을 전제하지 않는다.

#### 데이터 원천과 이용 조건 (§6.2, §6.3, 원칙 X)

- **FR-130**: 데이터 원천의 역할을 다음과 같이 고정한다. 같은 지표를 여러 공급원에서 중복 합산하지 않고, ECOS·KOSIS가 중복되는 지표는 주 공급원을 하나 정한다.

  | 원천 | 담당 정보 | 이용 조건 요약 |
  |---|---|---|
  | KRX OPEN API | 대표 ETF 식별·ETF 일별매매정보·KOSPI 시리즈·종목기본정보(2010-01-04 이후) | 개발·검증 단계 원천. 비상업·제3자 제공 금지. 화면에 '한국거래소 통계정보' 출처 표시 |
  | KDI 월간 경제동향 | 경제지표 후보 선정과 분야별 해석의 참고 근거 | 분야 분류·가중·거리·사례 선택은 Thorp 설계로 표현 |
  | ECOS | 금리·환율 등 거시 통계 | 출처 표시 시 상업 이용·가공·재배포 허용(한국은행 작성 통계). 타 기관 작성 통계는 해당 기관 조건 |
  | KOSIS | 물가·생산 등 국가 통계 | 출처 표시 조건, 분당 200회·요청당 40,000셀 한도 안 사전 집계 |
  | OECD | G20 경기선행지수 | 해외 경기 분야 공식 원천 |
  | DATA_GO_KR | 부족한 공공 통계·상품 시세 보완 | 일 1회 갱신·영업일 다음 날 13시 이후·비상업·재배포 금지. 개발 단계 보완 자료로만 |
  | 국내 경제 뉴스 RSS | 국내 뉴스 제목·시각·원문 링크(주 뉴스원) | 본문 저장·재배포 금지. 제목·링크 표시 허가 여부는 공개 전 매체 확인 |
  | GDELT | 국제 사건·해외 보도 메타데이터(보완원) | 15분 주기 번역 배포 파일을 기간·주제 제한 수집 |

- **FR-131**: KRX OPEN API와 DATA_GO_KR 시세는 개발·검증 단계의 원천으로만 쓴다. 실제 서비스 제공용 시세는 KRX 데이터상품 구매 여부와 비용을 사업 결정에서 다룬 뒤 별도 확보한다.
- **FR-132**: KRX 자료를 쓰는 화면에는 '한국거래소 통계정보' 출처를 표시한다. ECOS·KOSIS 통계는 출처와 작성기관을 표시한다. KOSIS·ECOS 정보를 플랫폼 없이 그대로 제3자에게 유료 제공하지 않는다.
- **FR-133**: API 인증키는 서버에서 관리하고 서비스 이용자에게 요구하지 않는다.
- **FR-134**: 자료를 이용할 수 없으면 범위를 줄이거나 허용된 대체 자료·명시된 예시 자료로 개발하고 자료 부족은 해당 결과에만 표시한다. 인증키가 필요한 실제 조회로 확인하기 전에는 개별 통계표·상품의 응답과 과거 범위를 확정된 것으로 쓰지 않는다.
- **FR-135**: 뉴스의 제목·매체·발행 시각·원문 링크 표시 방식이 매체의 사전 허가 대상인지 시장 흐름 뉴스 묶음 공개 전에 매체에 확인하고 회신을 기록한다.
- **FR-136**: KDI는 지표 후보 선정과 해석의 참고 근거로만 쓰고 Thorp의 분야 분류·가중치·거리·사례 선택을 KDI 공식 모델로 표현하지 않는다. KDI 보고서 문장은 외부 대조에만 쓰고 검색 입력으로 쓰지 않는다.

#### 검증·표시·완료 기준 (§7, 원칙 VII, 완료의 정의)

- **FR-140**: 선정 절차의 검증은 '내부 개발 구간 → 시간 순서 외부 평가 → 최종 잠금 평가' 순으로 한다. 마지막 12개월 잠금은 출발안이다. 선정 지표·허용 오차·분할 날짜·통계 보정·동률 처리·표시 후보 수·유사성 임계값·경제적 설명력 판정 기준은 시험 전에 고정하며 결정 항목이다.
- **FR-141**: 미확인 검증 항목 U01~U06은 기능 구현과 병행하며, 확인 전에는 기획서 §7.4의 '검증 전 동작'대로 움직인다. 미확인을 실패로 취급하거나 관측하지 않은 효과를 확정하지 않는다.

  | 항목 | 검증 전 동작 |
  |---|---|
  | U01 유사성의 이해·경제적 설명력 | 기본 검색과 원값 설명을 제공하되 '실제 투자 여건이 같다'고 일반화하지 않는다 |
  | U02 분야·지표 중복과 가중 영향 | 동일가중의 설계 의미를 공개하고 개별 지표 차이를 보인다. 중복 해소 완료라고 표현하지 않는다 |
  | U03 움직임 추가의 효용 | 상태 단독 거리를 사용한다. 추가 모델 검증 때문에 기본 검색 구현을 미루지 않는다 |
  | U04 충분한 유사성과 큰 차이 문턱 | 거리순 참고 후보를 제공하되 미판정으로 표시한다. 교정 전에는 합격이나 '충분한 사례 없음'을 단정하지 않는다 |
  | U05 ETF 연결 가능성과 실제 이용 가치 | 전략 진입은 공통 가용 범위를 명시하고 전체 탐색 전환을 제공한다. 결과 없음은 정상 처리하며 합성 이력이나 임의 대체로 채우지 않는다 |
  | U06 척도와 원천 자료 품질 | 자료가 유효한 범위에서 검색을 제공한다. 확인된 비정상 척도는 해당 분야/종합을 제한하고 조용히 지표를 빼서 계산하지 않는다 |

- **FR-142**: 기능·계산 확인은 기획서 §7.1 항목을 따른다. 대표 거래·현금·비용·분배금·공통 기간과 경제환경 검색의 중앙값·산포·대체 척도·지표/분야/종합 거리·기여도 합을 수기 또는 독립 계산으로 대조한다. 평가 경계를 넘는 이후 결과가 개발 자료에서 제거됐는지, 원시 가격·분배금·비용과 거래 내역이 일치하는지 확인한다.
- **FR-143**: 사용성 확인은 전략을 검증하려는 개인 6~8명에게 섹터 비중 비교 과제를, 그리고 경제환경 탐색 과제('현재와 고용환경이 가까운 과거를 찾고, 물가에서 다른 점을 설명한 뒤 같은 전략의 이후 행동을 비교하기')를 주어 관찰한다. 종합 비교를 열지 않아도 분야 탐색 과제가 끝나야 한다. 참여자·과제·일정은 결정 항목이다.
- **FR-144**: 구현 완료·사용성 확인·효과 입증은 구분해 보고하며 하나를 다른 것의 증거로 쓰지 않는다. 미사용 검증이 없거나 개선 근거가 없어도 기능을 되돌리지 않고 결과에 '미검증·개선 근거 없음·판단 보류'를 표시한다.
- **FR-145**: 제공받은 외부 PoC 기록은 스크립트를 재실행해 재검증하기 전에는 독립 검증 결과로 승격하지 않는다.

### Key Entities *(include if feature involves data)*

- **섹터 / 대표 ETF / 섹터-ETF 대응**: 섹터는 분석 단위(업종·테마 비중), 대표 ETF는 가상 매매 수단이다. 대응표는 상장일·기준 지수·구성종목 중복·유동성·추적 차이 정보를 갖고 버전으로 관리한다.
- **전략 / 파라미터 명세**: 다섯 전략 각각의 규칙 정의와, 전략별 파라미터의 후보 값·범위·간격·유효성 제약·기본값이다. 결정 뒤 버전으로 기록한다.
- **분석 (전략 실행)**: 섹터·비중·전략·파라미터·분석 기간·금액·비용·시나리오·데이터 마감/버전·엔진 버전과 진행 상태(대기/실행/완료/실패), 결과(핵심 숫자 3개·시계열·거래 내역·상세 지표·상태 표시)를 가진 한 실행 단위다. 포트폴리오 하나는 공유 현금·비중을 가진다.
- **비교 묶음**: 같은 조건(섹터 후보 집합·평가 기간·금액·비용·정보 이용 기준)에서 비교하는 결과들의 집합이다. 그래프에는 최대 두 결과를 동시에 보인다.
- **탐색 묶음 (자동 탐색)**: 고정한 전략군·섹터 후보 집합, 탐색 공간, 선정 규칙, 시드, 적용 한도와 후보별 실행 상태(완료/실패/제외/취소/미실행), 제외 사유, 선정 이유를 가진다. 내 기록에서 하나의 항목으로 보인다.
- **경제지표 등록표**: 17개 지표의 원천·통계표·항목·단위·변환·발표 시점·개편 연결·결측 처리·작성기관·공표 정밀도·최소 유효 척도다. 분야 매핑·계산 가중과 별도 버전으로 관리한다.
- **분야 / 분야-지표 매핑 / 계산 가중**: 7개 화면 분야와 지표 배치, 분야 내부·분야 간 가중이다. 화면 분류와 계산 가중은 별도 버전이다.
- **경제환경 검색 (질의)**: 검색 경로(시장 흐름 / 전략 결과), 모드(분야 g / 종합), 기준월 t와 그 근거(T_g/T_all/지정월), 공통 척도(m·s와 기준 기간), 전체 후보와 표시 후보, 제외 이유, 지표 원값·표준화 값, 지표/분야/종합 거리와 기여도, 검색 상태, 모델 버전, 자료 개정 기준, 가용성 필터 키, 유지율이다.
- **경제환경 사례**: 종료월과 관측 구간(3개월), 비슷한 점·다른 점 설명, 사후 평가 구간(63거래일 주·21거래일 보조), 시장 참고 정보(KOSPI), 연결된 전략 결과(사례 식별자·평가 날짜로 연결)이다.
- **뉴스 항목 / 뉴스 묶음**: 원문 URL·매체·언어·발행 시각·수집 시각·관련 섹터/주제·중복 식별자와 짧은 사실 요약이다. 같은 사건의 보도는 한 묶음이다. 본문은 저장하지 않는다.
- **학습 주제**: 질문 하나·예시 하나·설명·'이 예시로 비중 비교하기' 연결(예시 섹터·비중)이다. 진단 화면의 용어 도움말이 재사용한다.
- **내 기록 항목**: 완료한 분석·탐색 묶음·경제환경 탐색을 이름·섹터·전략·분석 기간·저장일로 가리키는 항목이다. 설정 변경은 새 항목(새 버전)이다.
- **사용자**: 내 기록의 소유자다. 식별정보는 계산 기록과 분리해 보관한다.
- **실행 측정 기록**: 실행 유형(단일 실행/탐색 묶음/분야별·종합 검색)별 대기 포함 응답 시간 분포·동시 처리량·자원 사용·실패·건당 원가와 재조회 구분이다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 새 사용자는 섹터 선택과 전략 선택 두 가지 필수 입력만으로 첫 분석을 완료하고 결과 첫 화면을 볼 수 있다. 그 외 모든 값은 기본값으로 진행된다.
- **SC-002**: 결과 첫 화면은 핵심 숫자 3개·비교 그래프 1개·요약 1문장·조건 한 줄로만 구성된다. 사용성 관찰에서 참여자가 상세 패널을 열지 않고 세 숫자의 의미(특히 고점 대비 최대 하락과 시작 금액 대비 손실의 차이)를 구분하는지 기록하고, 두 명 이상이 같은 단계에서 막히면 요약 화면을 수정한다.
- **SC-003**: 동일 버전의 재실행은 전략 단일 실행·자동 탐색·경제환경 검색 모두에서 100% 같은 결과를 낸다.
- **SC-004**: 같은 기준월·분야·자료/모델 버전·가용 후보 집합에서 비교 전략을 바꿔도 경제환경 후보 순위가 100% 같다.
- **SC-005**: 대표 거래·현금·비용·분배금·공통 기간과 경제환경 검색의 중앙값·산포·거리·기여도 합이 독립 계산과 사전 고정한 허용 오차 안에서 일치한다. 허용 오차는 결정 항목이며 시험 전에 고정한다.
- **SC-006**: 자료 부족·빈 뉴스·수집 지연·계산 실패·ETF 미상장·후보 없음·0 척도 상황은 100% 오류 화면 없이 정상 흐름과 한 문장 안내로 처리된다.
- **SC-007**: 유효성 제약을 위반하는 탐색 조합은 100% 계산 전에 제외되고 제외 사유가 기록된다.
- **SC-008**: 완료한 분석·탐색 묶음·경제환경 탐색의 100%가 FR-121·FR-122의 기록 항목을 갖고 내 기록에서 동일 버전으로 다시 열린다.
- **SC-009**: 전략을 검증하려는 개인 6~8명을 대상으로 섹터 비중 비교 과제와 경제환경 탐색 과제의 사용성 관찰을 수행하고, 설명 없이 완료한 참여자 수·막힌 단계·오해 유형을 기록한다. 경제환경 과제는 종합 비교를 열지 않고 완료할 수 있다.
- **SC-010**: 전략 단일 실행·자동 탐색 묶음·분야별 및 종합 검색별로 사용자 대기 시간 분포(대기 포함 중앙값·95백분위)·동시 처리량·자원 사용·실패율·건당 원가 측정값이 기록되고, 실행 상한이 그 측정값을 근거로 고정된다.
- **SC-011**: 화면 어디에도 추천 비중·주문 버튼·자동 단일 승자·우승 전략·사용자 간 랭킹·확률 표현·결제 단계가 없다. 리뷰 체크리스트에서 위반 0건이다.
- **SC-012**: KRX 자료를 쓰는 화면의 100%에 '한국거래소 통계정보' 출처가 표시되고, ECOS·KOSIS 자료 화면에 출처와 작성기관이 표시된다.
- **SC-013**: 경제환경 사례는 분야별·종합 모두 처음 3개, 더 보기 최대 10개를 넘지 않으며 후보 부족 시 빈자리를 채우지 않는다.

## Assumptions

- **이용 식별**: 전략 진단·시장 흐름·배우기는 사용자 식별 없이 이용할 수 있고, '내 기록' 저장·재조회는 식별된 사용자 단위로 동작한다고 가정한다. 인증·인가 방식은 constitution의 "합의되지 않은 영역"이므로 plan에서 근거를 남기고 정한다.
- **이용 환경**: 한국어 웹 서비스이며 데스크톱 브라우저를 우선한다. 모바일 대응 범위는 plan에서 정한다.
- **계산 위치**: 백테스트·탐색·검색 계산은 서비스가 수행하고 사용자 기기에서 하지 않는다. 기준 백테스트 엔진은 constitution의 "계산·데이터 규칙"이 정한 엔진을 그대로 따르며 이 spec에서 다시 정하지 않는다.
- **자료 확보 전 개발**: 대표 ETF 목록과 인증키 기반 실제 조회가 확정되기 전에는 허용된 대체 자료·명시된 예시 자료로 개발한다. 예시 자료 사용은 결과 옆에 표시한다.
- **모델 v1 기본값**: 기획서 §6.4.4가 확정한 경제환경 모델 v1 수치(FR-070~FR-078)는 그대로 적용한다. U01~U06 검증 결과에 따른 변경은 새 모델 버전으로만 제안한다.
- **기존 산출물과의 관계**: 현재 저장소는 단일 KRX 종목 모멘텀 백테스트 DEMO 상태다. 기존 API·메시지 스펙(`docs/specs/`)과 ADR(수수료 모델 등)은 이 spec에 맞춰 갱신 대상이며, 이 spec은 그 문서를 근거로 삼지 않는다.
- **분산 처리**: 기능 확대가 분산 Worker·Spark 도입을 뜻하지 않는다. 도입은 FR-035의 실측 뒤 판단한다.
- **뉴스 공개 시점**: 시장 흐름 뉴스 묶음은 매체 허가 확인(FR-135) 회신 전에는 내부 환경에서만 검증하고 공개하지 않는다.
- **법률 검토**: 투자자문·제품 출시 관련 법률 검토는 향후 고려사항이며 이번 개발의 선행 조건이 아니다. 현재 범위가 법적으로 비해당이거나 승인됐다고 단정하지도 않는다. (D13)
