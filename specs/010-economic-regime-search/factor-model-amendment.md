# 개정 제안 — Thorp 종합 비교를 경제 국면 요인 모델로 바꾼다 (모델 v3 제안)

**상태**: 제안 — **미승인, 구현 기준 아님.** 현재 구현 기준은 D21의 **모델 v1**이다.
**작성일**: 2026-09-24 (같은 날 1차 초안의 전체 PCA 설계를 버리고 이 판으로 다시 씀)
**관련 티켓**: S15P21E205-436
**막고 있는 것**: 없음. v1 구현과 002 FR-018 화면은 이 제안을 기다리지 않는다.
**선행 조건**: §7.1의 constitution 개정. 출발안(블록 주성분)을 쓰면 필요하고, 대안(블록 동일가중)을 쓰면 필요 없다.

> ## 먼저 읽을 것
>
> - 이 문서는 **바꾸자는 제안**이다. spec·plan·tasks·data-model·contracts의 현재 계약을 덮어쓰지 않는다.
> - constitution "하지 않는 것"은 *"마할라노비스·PCA·RRF를 기본 검색 모델에 넣는 것"* 을 금지한다.
>   출발안은 분야 묶음 안에서 주성분을 쓰므로 이 조항에 걸린다. 이 문서는 팀원 요청(2026-09-24)에 따라
>   그 조항을 좁히는 개정도 함께 제안한다(§7.1). 승인 전 실험은 FR-026의 내부 비교 기준 범위 안에서만 한다.
> - 모델 v2라는 이름은 [시대별 척도 제안](d21-amendment.md)이 쓰고 있어 이 제안은 **v3**로 부른다.

## 1. 무엇을 바꾸려는가

### 1.1 v1이 답하는 질문과 우리가 원하는 질문

| | v1 (현재) | v3 (제안) |
|---|---|---|
| 질문 | 지표 **값의 수준**이 지금과 가까웠던 때 | 경제가 **같은 방향으로 움직이던 국면**. 예: 실물은 꺾이고 물가는 오르던 때 |
| 지표 관계 | 보지 않는다. 지표마다 따로 차이를 재 평균한다 | 같은 경제 흐름에 속한 지표들이 함께 움직이는 정도를 요인으로 묶는다 |
| 결과의 모양 | 17개 지표 차이의 평균 | 경제 요인 4개로 된 **국면 벡터** 사이의 거리 |

팀이 처음 의도한 것은 두 가지다. 17개 지표의 관계를 반영해 시점별 경제 상태를 벡터로 나타내는 것, 그리고
그 묶음을 KDI 월간 경제동향이 경제를 읽는 틀을 참고해 세우는 것이다. v3는 이 의도를 따른다.

### 1.2 1차 초안(전체 PCA)을 버린 이유

17개 지표를 v1 입력 그대로 한 번에 주성분 분석하는 1차 초안에는 두 가지 결함이 있었다.

1. **시대를 찾는 모델이 된다.** 17개 중 5개(국고채 3년·원/달러 환율·두바이유·실업률·무역수지)는
   수준값으로 들어간다. 최근 10년 척도로 재면 금리가 높던 2000년대 초는 z가 극단값이 된다.
   그러면 주성분 하나가 사실상 "금리·환율 수준 = 연도" 축이 되어, 비슷한 국면이 아니라 가까운 연도를 찾는다.
2. **요인의 뜻이 흔들린다.** 기준월마다 자료가 달라 추출되는 요인의 구성이 바뀐다.
   요인에 이름을 붙일 수 없고, 같은 "요인 1"이 기준월마다 다른 것을 뜻한다.

v3는 두 결함을 각각 **변화량 입력**(§3.1)과 **경제 구조로 정한 요인**(§3.2)으로 막는다.

## 2. 제안 요약

| 항목 | v3 |
|---|---|
| 적용 범위 | **Thorp 종합 비교만.** 분야 검색은 v1 그대로 둔다(분야 검색이 기본이라는 D08 유지) |
| 입력 | 17개 지표의 **국면 입력** — 수준 지표는 전년 대비 변화로 바꾸고 증가율 지표는 그대로 쓴다(§3.1) |
| 척도 | v1과 같은 공통 척도 규칙(중앙값·MAD, IQR 대체, t-122~t-3, 최소 60개월 연속) |
| 요인 | 경제 블록 **4개**(실물 경기·대외 거래·물가·금융 여건)마다 요인 하나(§3.2) |
| 거리 | 비교 시점별 **표준화한 요인 점수 4개** 사이 유클리드 거리의 평균(§3.4) |
| 특이점 | 블록 안에서 요인이 설명하지 못한 **잔차**를 설명과 안내에만 쓴다. 순위에는 넣지 않는다(§3.5) |
| 당시 맥락 | 잔차가 큰 사례에 그 달의 공식 경제 판단과 발표 자료 링크를 붙인다. 검색 입력이 아니다(§4) |
| 설명 | 블록 이름과 실제 값·단위로 쓴다. 예: "실물 경기 흐름은 비슷했습니다(광공업생산 증가율 지금 2.1%, 당시 1.8%)" |

## 3. 계산 정의

### 3.1 국면 입력 — 수준을 변화로 바꾼다

값은 [008](../008-macro-indicator-registry/spec.md) FR-001의 변환값에서 만든다. 010은 원값을 쓰지 않는다(FR-015).

| 지표 | 008 변환 | v3 국면 입력 | 단위 |
|---|---|---|---|
| 전산업·광공업·서비스업생산, 소매판매액지수, 설비투자지수, 건설기성액, 수출, 수입, 취업자 수, 소비자물가, G20 경기선행지수 | 전년동월 대비 증가율 | **그대로** | % |
| 실업률 | 계절조정 비율 | 전년동월 대비 **변화폭** | %p |
| 국고채 3년 | 월 기말 | 전년동월 대비 **변화폭** | %p |
| 원/달러 환율 | 월 기말 | 전년동월 대비 **증가율** | % |
| 두바이유 | 월 평균 | 전년동월 대비 **증가율** | % |
| 무역수지 | 공식 금액 | 전년동월 대비 **변화액** | 억 달러 |
| 주택가격 | 전월 대비 증가율 | 최근 12개월 **누적 증가율** `Π(1+g)−1` | % |

- 12개월 전 값(주택가격은 12개월 연속 값)이 하나라도 없으면 그 달의 국면 입력은 **없다.** 채우지 않는다(FR-007).
- 이 규칙은 **요인 모델 전용**이다. 008 변환표와 분야 검색(v1)의 입력은 바꾸지 않는다.
- 전년 대비로 맞추는 이유: 증가율 지표 12개가 이미 전년동월 대비라, 나머지도 같은 시간 폭으로 맞춰야
  한 국면 벡터 안의 값들이 같은 "1년 동안의 움직임"을 말한다.
- 국면 입력이 v1 입력보다 12개월 늦게 시작하므로, 후보가 될 수 있는 첫 달도 그만큼 늦어진다(§6).

### 3.2 경제 블록 — 요인은 사람이 정한 구조로 둔다

| 블록 | 지표 | 기준 지표(부호 고정) | 수 |
|---|---|---|---|
| **실물 경기** | 전산업생산·광공업생산·서비스업생산·소매판매액지수·설비투자지수·건설기성액·취업자 수·실업률 변화폭(부호 반대) | 광공업생산 | 8 |
| **대외 거래** | 수출·수입·무역수지 변화액·G20 경기선행지수 | 수출 | 4 |
| **물가** | 소비자물가·두바이유 | 소비자물가 | 2 |
| **금융 여건** | 국고채 3년 변화폭·원/달러 환율 증가율·주택가격 누적 증가율 | 국고채 3년 | 3 |

- **근거**: KDI 월간 경제동향은 경기를 생산·소비·투자·고용(실물), 대외, 물가, 금융 순으로 서술한다.
  이 서술 구조를 **묶음 설계의 참고 근거**로만 쓴다. 블록 구성·가중·거리는 Thorp의 설계이며
  KDI 공식 모델로 표현하지 않는다(constitution "뉴스·거시 데이터"). KDI 문장은 검색 입력이 아니다(원칙 VII).
- **7개 분야와의 관계**: 분야 검색의 7개 분야는 그대로 둔다. 종합 비교만 4개 블록으로 다시 묶는다.
  노동은 실물 경기와, 해외 경기는 대외 거래와 함께 움직이므로 합쳤다. 화면에서 두 분류를 섞지 않는다(§5.3).
- 실업률 변화폭은 부호를 뒤집어 넣는다. 실업률이 오르면 실물이 약해지는 방향이라, 다른 지표와 방향을 맞추기 위해서다.
- **이 표는 2026-09-24에 팀이 확정했다**(PD-F4, 원칙 VII). 결과를 보고 지표를 옮기면 새 실험이다.

### 3.3 블록 요인 점수

1. 척도: 국면 입력마다 v1과 같은 공통 척도 규칙으로 m_t·s_t를 구해 z로 바꾼다(FR-005·FR-006).
   척도 구간에 연속 60개월이 없거나 MAD·IQR이 모두 0이면 종합은 '계산 불가'다(FR-008).
2. 블록 요인(결정 항목 PD-F1):
   - **출발안: 블록 제1주성분.** 척도 구간의 블록 z들로 상관행렬을 구하고, 제1주성분 적재 `w_b`로
     점수 `f_b = w_bᵀ z_b`를 만든다. 기준 지표의 적재가 양수가 되게 부호를 고정한다.
     블록 안에서 **함께 움직이는 정도가 큰 지표에 더 큰 무게**가 간다. 지표 관계를 반영하는 부분이 여기다.
   - **대안: 블록 동일가중 평균** `f_b = mean(z_b)`. 관계는 반영하지 않지만 설명이 가장 쉽고
     constitution 개정이 필요 없다. §8의 검증에서 출발안과 나란히 비교한다.
3. **요인 점수 표준화**: 척도 구간 안 f_b의 표준편차로 나눈 `f̃_b`를 쓴다. 한 블록(예: 지표가 8개인
   실물 경기)이 거리를 혼자 좌우하지 않고, 네 경제 블록이 같은 크기로 들어온다.
   이것은 Thorp의 설계 선택이며 "네 블록의 경제적 중요성이 같다"는 뜻이 아니다(FR-010과 같은 표시).
4. 적재·표준편차는 **기준월 t마다 척도 구간에서만** 추정하고, 질의와 모든 후보에 같은 값을 쓴다.
   블록이 구조로 고정되어 있어 기준월이 바뀌어도 요인의 뜻은 "그 블록의 공통 흐름"으로 같다.

### 3.4 국면 거리

- 비교 시점 k(t-2·t-1·t 중 자료가 있는 달)의 국면 벡터: `v(k) = (f̃_실물, f̃_대외, f̃_물가, f̃_금융)`
- 사례 거리: `D_R = mean_k ‖v_질의(k) − v_후보(k)‖₂`
- **비교 시점은 달 단위다.** 한 달에 네 블록이 모두 계산돼야 그 달을 쓴다. 블록 점수는 그 블록 지표가
  모두 있어야 계산된다. 빠진 달은 지표·월로 표기한다(FR-031). 세 달이 모두 빠지면 '계산 불가'다.
- 거리 변형(결정 항목 PD-F2): 출발안은 **유클리드**다. 블록 사이 상관까지 반영하는 4차원 마할라노비스
  (축소 공분산)는 §8의 비교 대상으로만 둔다. 4×4라 추정은 안정적이지만 설명이 어렵고 constitution이 금지한다.
- 후보 제한·표시·동률·±6개월 건너뛰기는 v1과 같다(FR-012~FR-014).

### 3.5 잔차 — 블록 안에서 엇갈린 움직임

블록 요인이 설명하지 못한 부분은 지표별로 `r_i = z_i − ŵ_i f_b`다. 출발안에서 `ŵ_i`는 적재에서 나온 계수이고,
대안(동일가중)에서는 `r_i = z_i − mean(z_b)`다. 잔차는 **같은 블록 안에서 한 지표만 다르게 움직인 정도**다.
예를 들어 수출은 늘었는데 수입이 급감한 달이 여기서 잡힌다. 요인 모델이 약하게 보는 "흔치 않은 조합"이 바로 이것이다.

| 쓰임 | 계산 | 화면 |
|---|---|---|
| 사례의 다른 점 보강 | 지표별 `mean_k \|r_질의,i − r_후보,i\|`가 큰 지표 최대 2개 | "대외 거래 흐름은 비슷했지만 수입 증가율은 지금 −8.2%, 당시 +3.1%로 달랐습니다" |
| 사례 특이 표시 | 후보 잔차 크기 `‖r_후보‖`가 그 기준월 척도 구간 잔차 크기 분포의 문턱을 넘음 | "이 기간에는 블록 안에서 엇갈린 움직임이 컸습니다" + 당시 맥락(§4) |
| 지금 시점 안내 | 질의 잔차 크기가 같은 문턱을 넘음 | "지금은 같은 흐름에 속한 지표들이 평소보다 엇갈려 움직이고 있습니다" |

- **순위·거리에는 넣지 않는다.** 넣으면 요인으로 걸러 낸 잡음이 다시 들어온다.
- 문턱(결정 항목 PD-F3)은 **시험 전에 고정한다.** 출발안은 척도 구간 잔차 크기의 90번째 백분위다.
- 백분위나 잔차 값을 숫자로 보이지 않는다(FR-017·FR-022). 검색 상태(FR-019)도 바꾸지 않는다.
- 세 표시는 신뢰 범위를 말하는 표시이므로 FR-037 접근성 요구를 적용한다.

## 4. 당시 맥락 — 특이 사례를 설명하는 텍스트

잔차가 문턱을 넘은 사례(§3.5)에는 그 달에 **무슨 일이 있었는지** 볼 수 있는 자료를 링크로 붙인다.

- **입력이 아니다.** 순위·거리·잔차 계산에 쓰지 않는다(FR-004, 원칙 VII).
- **원인으로 단정하지 않는다.** "당시 자료"로만 표시하고, 수익이나 차이의 원인이라고 쓰지 않는다(012 US3, FR-022).
- **당시 발행된 자료만 쓴다.** 발행일을 확인할 수 없는 자료는 붙이지 않는다(012, 원칙 V).
- 본문을 저장하거나 보이지 않는다. 제목·출처·발행일·원문 링크만 쓴다(constitution "뉴스·거시 데이터").
- 자료원·이용 조건·범위는 조사 중이다. 조사 결과로 이 절의 **자료원 표**를 채운 뒤 확정한다(결정 항목 PD-F6).
  2026-09-24 1차 조사에서 확인한 것은 둘이다. 등록된 RSS 7개는 최근 1~2일치만 준다. 매경·경향의 과거 기사
  수집은 매체 정책에 막혀 있다.

## 5. 화면·설명

### 5.1 사례 설명

- **블록 단위**: 네 블록 중 차이가 작은 쪽 최대 2개와 큰 쪽 최대 2개를 고른다. 블록 이름에 대표 지표의
  **국면 입력 실제 값과 단위**를 붙여 쓴다. FR-016의 분야 단위 규칙을 블록에 적용한 것이다.
- **순위와 설명이 같은 값을 가리킨다.** 설명에 쓰는 값은 순위에 들어간 국면 입력 그대로다(FR-015가 막으려던
  모순을 피한다). 예: 국고채는 "지금 1년 전보다 0.4%p 낮고, 당시에는 0.6%p 낮았습니다"로 쓴다.
- 문장은 템플릿 조립만 쓰고, 금지 표현 목록(FR-022)을 그대로 적용한다.

### 5.2 블록 이름

- 블록 이름(실물 경기·대외 거래·물가·금융 여건)은 §3.2가 고정한 Thorp의 분류 이름이다.
- "성장 요인" 같은 통계적 요인 이름이나 KDI 공식 판단처럼 읽히는 표현은 쓰지 않는다.
- 경기의 좋고 나쁨을 점수로 보이지 않는다(constitution "하지 않는 것").

### 5.3 분야 검색과의 구분

- 분야 검색(7개 분야, v1)과 종합 비교(4개 블록, v3)는 **묻는 질문이 다르다.** 앞은 값의 수준, 뒤는 움직임의 국면이다.
  그래서 분야 검색 1위와 종합 1위가 달라도 모순이 아니다.
- 종합 화면에 "경제 전체의 움직임(1년 변화)이 비슷했던 때"라는 뜻을 한 문장으로 밝힌다.
- 7개 분야 거리를 종합 화면에 섞어 보이지 않는다.

## 8. 채택 전에 할 검증

검증 설계와 판정 기준은 **실행 전에** 이 절에 확정해 적는다(원칙 VII). "출발안"은 확정 전까지 바꿀 수 있다.
확정 뒤 결과를 보고 바꾸면 새 실험이다.

### 8.1 비교 대상

모두 같은 자료·등록표 버전, 같은 기준월 표본, 같은 후보 제한·표시 규칙으로 비교한다.

| 이름 | 입력 | 요인 | 거리 | 역할 |
|---|---|---|---|---|
| v1 | 008 변환값 | 없음 (7분야 동일가중) | 지표 차이 평균 | 기준선 |
| **v3** | 국면 입력 | 블록 제1주성분 | 유클리드 | 채택 후보 (출발안) |
| v3-eq | 국면 입력 | 블록 동일가중 | 유클리드 | 채택 후보 (대안) |
| v3-maha | 국면 입력 | 블록 제1주성분 | 4차원 마할라노비스 | 내부 비교 기준 |
| pca-all | 국면 입력 | 17개 전체 PCA (누적 70%) | 유클리드 | 구조 주도의 효과를 보는 비교 기준 |

v1과 v3를 비교하면 **입력과 구조를 함께 바꾼 효과**가 나온다. 입력만의 효과를 따로 보려면 v1 규칙에
국면 입력만 넣은 변형도 비교한다(v1-change).

### 8.2 정답 기준 — 외부 라벨, 검색 입력 아님

- **통계청 경기순환 기준일**: 정점·저점으로 월마다 확장·수축을 나눈다. 사후 확정값이라 역사 탐색 평가로만 쓴다(FR-027).
- **KDI 월간 경제동향 경기 판단**: 월별 판단 문장을 사람이 5단계(뚜렷한 개선 / 개선 / 혼조 / 둔화 / 뚜렷한 둔화)로 옮긴다.
  옮김 규칙과 두 사람의 일치 확인 절차를 실행 전에 고정한다. **외부 대조에만** 쓴다(원칙 VII).
- **알려진 국면 목록**: 실행 전에 고정한다. 출발안은 2003 카드 사태 여파, 2008-09~2009-03 금융위기,
  2011 유럽 재정위기, 2020-03~2020-06 코로나 충격, 2022 금리 급등기다.
- **쓰지 않는 것**: KOSPI·전략 수익률. 이후 성과가 좋아지는 쪽으로 모델을 고르지 않는다(FR-025).

### 8.3 측정 항목

| 항목 | 정의 | 무엇을 보나 |
|---|---|---|
| 국면 일치율 | 상위 3개 중 질의와 같은 경기순환 국면인 비율 | 경기 국면을 찾는가 |
| 판단 거리 | 상위 3개와 질의의 KDI 판단 단계 차이 평균 | 외부 해석과 맞는가 |
| **시대 쏠림** | 상위 3개와 질의의 종료월 간격 중앙값, 그리고 최근 5년 안 후보 비율 | "가까운 연도 찾기"가 되지 않았는가 (§1.2 결함 1의 확인) |
| 국면 사례 재현 | 알려진 국면 안의 달을 질의로 했을 때, 상위 3개에 다른 알려진 국면이 들어오는 비율 | 비슷한 충격을 서로 찾는가 |
| 순위 안정성 | 자료 버전 두 개 사이, 그리고 지표 하나를 뺐을 때의 상위 3개 유지율 | 개정·잡음에 흔들리지 않는가 |
| 특이 포착 | 알려진 국면 안에서 잔차 안내가 켜지는 비율과, 그 밖에서 켜지는 비율 | §3.5가 약점을 드러내되 남발하지 않는가 |

유지율은 내부 검증 값이며 화면에 보이지 않는다(FR-031).

### 8.4 구간과 판정

- **구간**: 내부 개발 → 시간 순서 외부 평가 → 최종 잠금(원칙 VII).
  - PD-F1~F3은 내부 개발 구간에서만 정한다.
  - 분할 날짜는 008 자료 범위를 확인한 뒤 실행 전에 적는다. **미정: 실제 자료 범위를 확인하지 않았다.**
- **채택 판정 출발안**: 외부 평가 구간에서 v3(또는 v3-eq)가 세 조건을 모두 만족하면 채택안으로 올린다.
  - 국면 일치율과 판단 거리 둘 다 v1보다 낫다.
  - 시대 쏠림이 v1보다 심하지 않다.
  - 순위 안정성이 v1보다 낮지 않다.
- 최소 차이·표본 수·통계 보정은 실행 전에 PD-F5로 확정한다.
- v3와 v3-eq의 차이가 판정 기준 안에서 구분되지 않으면 **v3-eq를 택한다.** 설명이 쉽고 constitution 개정이 필요 없다.
- 결과는 '탐색 결과 / 미사용 검증 결과 / 미검증'으로 구분해 기록한다. 문서나 구현의 완료를 효과 입증으로 보지 않는다.
- 실험 코드는 `ai/` 아래 내부 스크립트로 두고 운영 배치(`precompute_regime.py`)에 넣지 않는다.
