# D21 · constitution 개정 제안 — 시대별 척도 비교 검증 (모델 v2)

**상태**: 검증 대기 제안 — **기본 모델 변경은 보류**, 현재 구현 기준은 D21의 **모델 v1**
**작성일**: 2026-09-16 (같은 날 D21 원문 확인 및 v1 구현 기준과 v2 제안 분리)
**막고 있는 것**: 없음 — [spec.md](spec.md) PD-08과 [tasks.md](tasks.md) M1~M9는 v1 기준으로 진행한다.
M10은 구현 완료 뒤 사용성 관찰이며, v2 채택 승인과는 별개다.

> ## 먼저 읽을 것 — 구현 계약과 변경 제안을 구분한다
>
> D21은 공통 척도와 시대별 척도를 비교해 **공통 척도를 기본으로 채택**했다.
> 이 문서는 그 선택을 바꿀지 검증하기 위한 제안이다. v2의 우월성이 입증됐거나 변경이 승인됐다는
> 뜻이 아니다. **v2는 폐지하지 않고 보존하되, 운영 구현·API·화면에 추가하지 않는다.**
> 현재 구현 계약은 spec·plan·tasks·data-model·contracts이며, 이 문서가 이를 덮어쓰지 않는다.

| 앞선 주장 | 정정 |
|---|---|
| 시대별 척도는 D21이 미처 검토하지 않은 개선이다 | D21이 이미 비교한 대안이다. 다시 제안할 수 있으나 새로운 검증 근거가 필요하다 |
| 환율 하나 때문에 옛 시기가 사실상 배제된다 / 최근 10년만 실질 탐색한다 | 실제 후보 순위·기여도 측정이 없는 가설이다. 척도 산출 구간 10년과 후보 탐색 범위는 다르다 |

| 나머지 12개는 증가율이라 드리프트 영향이 없다 | 증가율 자체의 중심·산포도 시대별로 달라질 수 있다. 변화율 변환만으로 영향이 없다고 보장할 수 없다 |
| 문제는 금융·주택에 집중된다고 실측했다 | 등록표의 지표 수와 변환을 센 것이다. 실제 검색 영향이나 순위 변화는 아직 측정하지 않았다 |
| 공통 척도는 후보월 이후 자료를 쓰므로 미래 정보 누수다 | 현재 정보로 과거를 비교하는 역사 탐색과 당시 의사결정 재현을 구분해야 한다. 후보월 이후라는 이유만으로 누수라고 단정하지 않는다 |
| 옛 사례가 순위에서 밀리면 기능이 동작하지 않는다 | 실제 입력값의 유사성을 찾는 목적이라면 수준이 다른 사례가 멀게 나오는 것은 의도한 결과일 수 있다 |
| 화면에 원값과 두 척도를 보이면 오해를 막을 수 있다 | 설명을 돕는 설계 가설이다. 사용자 이해가 확인됐다는 뜻이 아니며, v1도 보조 설명으로 당시 기준을 제시할 수 있다 |
| v2의 계산량은 늘지 않는다 | 후보월별 재사용은 가능하지만 전체 계산량·적재 비용의 우열은 실행 조건을 맞춰 측정해야 한다 |

## 3. 등록표에서 확인한 범위 ([008](../008-macro-indicator-registry/spec.md) FR-001)

| 분야 | 지표 수 | 수준으로 들어가는 지표 | 분야 안 명목 비중 합 |
|---|---|---|---|
| 생산 | 3 | — | 0 |
| 소비·투자 | 3 | — | 0 |
| 대외거래 | 3 | 무역수지(공식 금액) | 1/3 |
| 노동 | 2 | 실업률(계절조정 비율) | 1/2 |
| 물가·원자재 | 2 | 두바이유(월 평균) | 1/2 |
| 금융·주택 | 3 | 국고채 3년·원/달러 환율(월 기말) | 2/3 |
| 해외 경기 | 1 | — | 0 |
| **합계** | **17** | **5개** | 종합 명목 비중은 아래 식 |

분야 동일가중 기준 수준 지표의 **명목 비중 합**은 `(1/3 + 1/2 + 1/2 + 2/3) / 7 = 2/7 ≈ 28.6%`,
환율의 명목 비중은 `1/7 × 1/3 = 1/21 ≈ 4.8%`다. 실제 종합 거리 기여도는
`w_i × E_i / Σ(w_j × E_j)`이며 후보마다 달라진다. 예를 들어 환율의 E만 20, 나머지는 모두 1이면
환율의 실제 거리 기여도는 **50%**다. 이 예는 수식 설명용이며 실제 경제자료 측정값이 아니다.

금융·주택은 수준 지표 명목 비중이 높으므로 우선 살펴볼 분야다. **v1·v2의 결과 차이가 가장 크다는
결론이나 다른 분야에는 영향이 없다는 결론은 이 표로 내리지 않는다.**

## 4. v2를 검증할 이유와 방법

### ① 유사성의 의미가 다르다

v1은 질의 직전 공통 척도로 실제 입력값과 경로의 차이를 비교한다. 지표별 반올림 전 차이는
`|(x_t-m_t)/s_t - (x_c-m_t)/s_t| = |x_t-x_c|/s_t`다.
v2는 `|(x_t-m_t)/s_t - (x_c-m_c)/s_c|`로 각 시대의 평소 대비 위치 차이를 비교한다.
여기서 x는 008이 정한 변환 후 입력값이다. **계산 오류 수정이 아니라 검색 질문의 변경**이다.

### ② 같은 표본에서 두 종류의 차이를 따로 본다

검증 전에 자료·등록표 버전, 질의 기준월, 분야, 비교 시점과 측정 항목을 고정한다.
수익률이 좋은 사례가 나오는 방향으로 표본·척도·가중을 고르지 않는다(FR-025).

| 비교 | 고정할 조건 | 확인할 것 |
|---|---|---|
| 거리 정의 비교 | 두 방식 모두 계산 가능한 공통 후보 집합, 동일 입력·가중·표시 규칙 | 상위 사례 교체, 원값·3개월 경로 차이, 지표별 실제 기여, 수준·산포 차이 |
| 후보 가용성 비교 | 같은 질의·자료에 각 모델의 후보 조건을 적용 | 유효 후보 수·최초 후보월·제외 사유. v2의 후보 직전 이력 부족과 0 척도를 따로 집계 |
| 사용자 이해 비교 | 실제 값·단위·검색 이유를 함께 제시하고 두 방식의 제시 순서를 교차 | 상대 위치를 수치 일치·같은 투자 여건으로 오해하는지, 찾으려던 사례에 부합하는지(U01) |
| 계산 비용 비교 | 같은 자료·실행 환경, 초기 계산과 증분 갱신을 구분 | 소요 시간·계산 횟수·저장량. 후보월 재사용 여부도 기록 |

오래된 사례가 더 많이 나오거나 이후 성과가 좋다는 사실만으로 우수한 모델이라고 판정하지 않는다.
이 비교는 **내부 실험**이며 두 모델의 운영 API나 선택 화면을 만들겠다는 요구가 아니다(FR-026).
검증 표본과 채택 판정 기준은 실행 전에 기록하며, 미정인 수치를 임의로 확정하지 않는다.

### ③ 시간 기준을 구분한다

010은 최신 개정자료를 이용한 **역사 탐색**이다. 당시 의사결정 재현은 그 의사결정 시점에 공개된
자료·발표일·빈티지로 척도와 입력을 구성했는지 별도로 확인해야 한다(FR-027).
v2도 최신 개정값을 쓰는 동안 당시 재현을 보장하지 않는다. 이 구분은
[FRED·ALFRED의 자료 기준 설명](https://fred.stlouisfed.org/docs/api/fred/fred_vs_alfred.html)과도 일치한다.

## 5. v2가 감수하는 부담

### ① 실제 수준과 산포 차이가 거리에서 제거된다

현재 금리 3%와 과거 금리 10%가 각각 그 시대의 중앙값이면 둘 다 z=0이다.
산포 200원인 시기의 z=1과 산포 50원인 시기의 z=1도 같다. 상대 위치는 같지만 실제 조건은 다르다.
사용 목적에 적합한지는 아직 확인하지 않았다.

### ② 후보 가용 범위가 줄 수 있다

후보 c도 `c-122~c-3`에서 최소 60개월 연속 자료가 필요하다. 단순 연속 계열의 첫 자료월을 S라 하면
첫 가능한 후보 종료월은 **S+62개월**이다(척도 S~S+59, 관측 S+60~S+62).
실제 범위는 지표별 시작·결측·0 척도와 분야 결합에 따라 더 좁아질 수 있다. v1은 후보 직전 이력을
자격 조건으로 요구하지 않으며, 시대별 보조 설명만 제한한다(FR-012·FR-017).

### ③ 기본 검색 이유가 바뀐다

D21의 “당시 평소 대비 위치는 기본 검색 이유로 혼용하지 않는다”와 충돌한다.
원값을 함께 보여주는 것만으로 이 충돌이나 사용자 오해가 해소됐다고 할 수 없다.

### ④ 아직 검증 결과가 없다

이 문서에는 실제 자료 대조·U01 관찰·성능 실측 결과가 없다. v1 유지도 우월성 입증이 아니라
**현재 합의된 구현 기준의 유지**다. 문서 작성량과 체크리스트 완료는 모델 채택 근거가 아니다.

## 6. 채택한다면 무엇을 바꿔야 하나 (현재 미적용)

### 6.1 기획서 D21 — 세 항목

| 항목 | 현재 v1 | v2 채택 시 검토할 변경 |
|---|---|---|
| 결정 | 공통 척도를 질의·모든 후보에 동일 적용 | 질의는 t 직전, 후보는 c 직전 척도로 각각 표준화 |
| 화면·표시 | 실제 값·경로가 기본 검색 이유, 시대별 위치는 보조 | 상대 위치가 기본 검색 이유임을 밝히고 실제 수준·산포 차이도 함께 설명 |
| 검토한 대안 | 공통 척도를 기본으로 채택 | 검증 결과·채택 근거·감수하는 비용을 남기고 변경 여부 결정 |

### 6.2 constitution 개정 — 영향 다섯

| # | 위치 | v2 채택 시 필요한 검토 |
|---|---|---|
| C1 | 원칙 V의 공통 척도 | 질의·후보에 같은 척도를 적용하는 원칙 변경 |
| C2 | 용어 사전 | 공통 척도와 시점별 척도의 기본·대안 역할 변경 |
| C3 | 경제환경 검색 | 시대별 위치를 보조로만 제공하는 규칙 변경 |
| C4 | spec에 위임하는 모델 명세 목록 | 기본 모델·내부 대안의 표현 동기화 |
| C5 | 원칙 VI의 0 척도 처리 | 질의 척도 실패와 후보 척도 실패의 결과를 구분 |

이 변경은 원칙 재정의이므로 채택 시 MAJOR 개정 대상이다. **기존 미승인 4.0.0 초안은 본문에서
분리했으며 효력이 없다.** 3.3.0 Git·Jira 초안은 별개이므로 내용과 미승인 상태를 유지했다.
실제 개정 버전은 채택 시점의 승인 버전에서 정하며, 검증 결과만으로 승인 절차를 대신하지 않는다.

### 6.3 작성했던 v2 설계 보존

v2 설계는 Git 커밋 `4d9cddc`의 `specs/010-economic-regime-search/`에 보존돼 있다.
질의·후보 척도 분리(`query_scale`/`case_scale`, `queryScale`/`caseScale`), 후보 척도 부족 제외와
태스크 설계를 다시 검토할 수 있다. **현재 파일은 v1 구현 계약**이며, 과거 설계를 그대로 적용하지 않는다.

| **A (현재 구현 기준)** | D21 유지, v1 | 실제 입력값·경로의 차이를 같은 척도로 비교 | 시대별 분포 변화가 사용자 목적에 미치는 영향 |

| C | 수준 지표 5개만 시대별 척도 | 특정 지표에 한정해 상대 위치 비교 | 거리 해석이 섞이며 5개 선정 근거도 검증 필요. D21 변경 대상 |
| D | 008의 입력 변환 변경 | 지표 의미에 맞춘 변환을 검토할 수 있음 | 수준 정보 손실 가능성, 등록표·모델 버전 및 기획 결정과의 정합성 검토 |

현재는 A로 개발한다. B~D는 선택지가 남아 있다는 뜻이며 이번 구현 태스크에 추가하지 않는다.

## 8. 지금의 결정과 재논의 조건

1. **v1을 구현 기준으로 유지한다.** spec·plan·tasks·data-model·contracts·quickstart를 같은 기준으로 맞춘다.
2. **v2 제안은 검증 대기로 보존한다.** 실제 자료 비교와 사용자 이해 결과가 나오면 판단 근거를 추가한다.
3. **채택 시 별도로 확정한다.** D21 변경과 constitution 승인 절차를 거친 뒤 관련 spec·계약·태스크를 함께 갱신한다.

M1~M9의 v1 구현은 v2 검증·승인을 기다리지 않는다. M10의 기본 사용성 관찰을 v2 비교 실험 결과로
간주하지 않으며, 실제 비교를 수행한 경우에만 그 조건과 결과를 별도로 기록한다.
