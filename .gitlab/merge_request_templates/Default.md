# 공통 확인
- [ ] **순위 배지·추천 표현 0건** — 우리는 진단을 하지 결과를 추천하지 않는다(원칙 III). 표시 후보는
      순서 있는 목록이 아니라 정렬 지표를 밝힌 집합이다. "1위", "추천", "최적", 우승 배지를 넣지 않았다
- [ ] **결제·포인트·상품 선택 단계 0건** — 이번 범위의 "하지 않는 것"이다(FR-010)
- [ ] **전략 ID 상수·전략별 분기 0건** — 전략 목록·파라미터 기본값·허용 범위·단위를 코드에 두지 않았다.
      전략은 등록표가 돌려주는 값으로만 다루며 `strategyId` 로 `switch`·`if` 분기하지 않았다(FR-025).
      전략이 늘어도 이 코드를 고치지 않아도 되는지 확인했다
- [ ] **계산하지 않은 값을 0으로 채우지 않았다** — 제외·실패·미실행 후보의 성과는 `null` 이고,
      화면은 그것을 "0%" 가 아니라 사유와 함께 보인다(FR-011, 원칙 VI)
- [ ] **검증되지 않은 것을 검증된 것처럼 보이지 않는다** — 평가 분할이 없으면 `UNVALIDATED` 이며
      이는 "통과"가 아니라 "말할 수 없음"이다. 라벨을 결과와 항상 함께 보인다(FR-015, 원칙 VII)
