**판정**: 자동으로 잴 수 있는 기준(SC-001·SC-003·SC-004)은 충족했고 SC-002 도 자동 검사는 통과했다. 플래그 `THORP_ASSISTANT_ENABLED_SCOPES=RESULT` 는 §5 의 두 명 채점에서 SC-002 위반이 0건으로 확인된 뒤에 배포 설정에 넣는다. 이 문서는 그 전까지 플래그를 켜지 않은 상태의 기록이다.

불일치 여섯 건은 관문 기준 위반이 아니라 답의 쓸모·경로 문제다. 고치려면 프롬프트 손질이고 티켓으로 세우지 않았다:

- R02 "비용을 빼고 얼마가 남았어?" → 비용 차감 후 전체 수익률·종료 자산을 고르지 못함.
- R15·R16 저점 날의 보유 질문에 도구 없이 설정·기여 값으로 답함. "가장 크게 줄었던 때 보유" 는 `getDeepestDrawdownWindow` → `getPositionsOn` 이라는 지시가 프롬프트에 없다.
- B05·B06 "다른 결과 보여 줘"·"비교 대상이랑 뭐가 달라?" 를 범위 밖으로 보내지 못함. 프롬프트의 범위 밖 목록에 요청형 문장 예를 더하면 잡힌다.
