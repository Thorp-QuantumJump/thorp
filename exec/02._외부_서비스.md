- 가입·키 발급이 필요한 외부 서비스와, 키의 위치에 대한 문서입니다.

## 키 확인 방법

```bash
# 서버에서, 값은 출력하지 않고 채워졌는지만 본다
cd /home/ubuntu/S15P21E205/infra
for k in KRX_API_KEY ECOS_API_KEY KOSIS_API_KEY DATA_GO_KR_SERVICE_KEY MAIL_USERNAME MAIL_PASSWORD; do
  printf '%-24s %s\n' "$k" "$(grep -q "^$k=." .env.prod && echo 있음 || echo 비어있음)"
done
```

시장 지표 조회는 캐시(`MARKET_CACHE_TTL` 6h)와 실패 냉각(`MARKET_FAILURE_COOLDOWN` 30s)을 둔다. 키가 틀리면 그 지표만 "제공되지 않음"으로 보이고 나머지는 동작한다.
